# Audit of the planar Todd/balancing route

## Verdict

No rank-uniform positive Todd decomposition has been proved.  Two natural
versions of that proposed bridge have exact finite obstructions:

1. pointwise positivity of the simplicial local BV terms is false already for
   a realized rank-five hive face; and
2. positivity cannot follow only from nonnegativity of a type-A volume
   chamber polynomial together with the Dahmen--Micchelli cocircuit
   (balancing) equations.

Neither obstruction is a counterexample to KTT.  In the realized rank-five
example, forced flat-rhombus closure enlarges the negative simplicial cell to
a nonsimplicial normal cone whose total BV value is positive.  Thus the only
surviving version of the proposed route needs a genuinely hive-specific
theorem about **closed planar coarsenings**, not a generic Todd, root-system,
or fixed-simplex argument.

## 1. Exact meaning of a balancing certificate

Fix a complete normal fan (or a coarsening) `Sigma` and a codimension `q`.
Write `a_q` for the vector of BV/Todd weights on the `q`-dimensional normal
cones.  Let

```
partial_q : Q^{Sigma(q)} -> E_q
```

be the Minkowski boundary map.  The nonnegative balanced weights form

```
W_q(Sigma) = {w >= 0 : partial_q w = 0}.
```

A componentwise nonnegative representative of `a_q` modulo balancing exists
exactly when

```
a_q + partial_q^T y >= 0
```

for some rational `y`.  By rational Farkas duality, this is equivalent to

```
<a_q,w> >= 0  for every w in W_q(Sigma).                 (1)
```

This formulation separates the missing theorem from local BV computation.
Horn factorization can remove separating boundary coarsenings.  To prove KTT
by this route one still needs a rank-uniform generator theorem saying that,
for every 2-connected primitive-interior hive coarsening, the cone `W_q` is
generated by weights on which (1) is visibly nonnegative (for example the
proposed rhombus stars and separating corridors).  No such generator theorem
is presently available in the artifacts or in the cited primary sources.

Fulton--Sturmfels identify the operational Chow cohomology of a complete
toric variety with Minkowski weights; this is the standard source for the
balancing language:

<https://arxiv.org/abs/alg-geom/9403002>.

The point `(26,33,36,37,43,46)` has every rhombus slack positive, so the hive

The full rank-four normal cone has five extreme rays.  A saturated normal-cone
subdivision has three maximal cells with exact BV values

```
  39/3200,   -349/28800,   3587/120960.
```

Thus a genuine simplicial local term is negative.  Nevertheless Berline--
Vergne's simple-valuation identity on normal cones gives

```
39/3200 - 349/28800 + 3587/120960
  = 17977/604800 > 0.                                  (2)
```

So assigning a nonnegative weight independently to every primitive
four-rhombus simplex is impossible, but (2) also shows why that failure is not
a KTT counterexample: hive flatness forces the negative simplex to occur
inside a larger closed normal cone, and the closed cone is positive.

## 3. Exact obstruction to a generic type-A balancing proof

Let `Phi+` be the ten positive roots of `A4`, identified with the oriented
edges `e_i-e_j`, `i<j`, of `K5`.  Give the five vertices the potentials

```
(1,0,1,1,0)
```

and let `L` be the resulting covector.  Put `p=L^4`.  Then `p` is globally
nonnegative.

The cocircuits of the graphic root configuration are the nontrivial cuts of
`K5`.  There are fifteen cuts up to complement and they have size four or six.
A size-six cocircuit derivative kills `p` by degree.  Every size-four cut is a
vertex star and contains an edge on which `L` vanishes.  Hence every cocircuit
derivative kills `p`, so

```
p belongs to D(Phi+),
```

the exact Dahmen--Micchelli polynomial space.  Notice that `K5` is
4-vertex-connected, so this witness has no separating-graph factorization.

On the positive roots, the values of `L` are

```
(1,0,0,1,-1,-1,0,0,1,1).
```

Exact multiplication of the Todd symbols gives

```
product_{alpha>0} Todd(z L(alpha))
  = 1 + z + z^2/4 - z^3/12 - z^4/20 + O(z^5).
```

Consequently

```
[product Todd(D_alpha)] p  at L(x)=N
  = N^4 + 4 N^3 + 3 N^2 - 2 N - 6/5.                  (3)
```

This is a finite separation certificate.  Modulo the cocircuit annihilator,
any conical combination of point-evaluation functionals that is nonnegative
on every globally nonnegative element of `D(Phi+)` must evaluate nonnegatively
on `p`.  The linear and constant coefficient functionals in (3) evaluate to
`-2` and `-6/5`.  Therefore the Todd functional has no such nonnegative
representative modulo the generic type-A cocircuit relations.


McSwiggen's deconvolution formula is the primary source for the exact Todd
operator on tensor-product multiplicities:

<https://arxiv.org/abs/1909.12278>.

The scope is important.  The polynomial `p` has not been shown to be an
actual hive volume chamber polynomial.  Thus (3) kills proofs using only
nonnegativity plus Dahmen--Micchelli membership; it does not kill a stronger
identity special to the much smaller cone of actual hive chamber polynomials.

## 4. Why the proposed induction does not presently close

The codimension-four example isolates the missing operation.  A negative
Todd cell can become harmless only after taking the forced flat-rhombus
closure and then applying the full normal-cone valuation.  Generic type-A
cocircuit balancing does not force this repair, as Section 3 shows.

An induction on planar ears or on the number of flat rhombi would therefore
need all three of the following statements:

1. deleting an ear preserves the saturated intrinsic face lattice;
2. the BV class changes by a nonnegative combination of a fixed list of local
   star/corridor classes; and
3. every 2-connected primitive-interior coarsening admits such a deletion.

The first two statements are not consequences of planar graph theory.  Hive
normal cones already have lattice indices two and four, and the first
negative Bernoulli term occurs in Todd order four.  The exact negative cell
in Section 2 shows that the change in (2) cannot be termwise nonnegative.
No invariant was found that makes the required correction local and
rank-independent.

Accordingly, continuing through codimensions five, six, and so on would be an
unbounded fixed-codimension cascade, not a proof of full KTT.  The direct route
must stop here unless one proves the missing rank-uniform generator theorem
for the cones `W_q` in (1), or finds an actual balanced weight with negative
pairing, which would refute this balancing formulation.
