# Wrapped N2 direct attack — exact status

This note is **not** a proof of C144.  It records the exact finite
certificates, two falsified shortcuts, and the remaining local statement.

## Direct bridge

Put `delta=e-h` and

    S = sum_H |E_H cap W|.

The wrapped proposal is

    S + max(0,2 delta-g) <= 2(M_z(K)-h).                 (WN2)

Since the noncentral window is covered,

    S >= |W| = min(g,2 delta-1).

If `2 delta-1<=g`, (WN2) gives
`2(M_z-h)>=2 delta-1`; integrality gives `M_z-h>=delta`.
If `2 delta-1>g`, it gives
`2(M_z-h)>=g+(2 delta-g)=2 delta`.  Thus in both cases
`M_z>=h+delta=e`, exactly the registered W144-R frontier.

## Falsified shortcuts

1. The arbitrary-`z` component bound `|E_H cap W|<=2 mu_z(H)` is false.
   The exact counterexample is in `naive_component_counterexample.md`.
2. Uniform averaging over all `z!=m` is false.  Graph6 `Fh_gG` has exact
   averaging slack `-4`; see `averaging_counterexample.md`.  WN2 itself is
   tight on the same graph.

## Rigorous adjacent-root reduction

Choose an `e`-realizer `x` of maximum height `h=d(x,K)`, an anchor `m`, and
let `z` be either neighbor of `m` on `K`.  Suppose a component `H` of `G-K`
is attached only at `z` and covers some `sigma in W`; choose `y in H` with
`d(sigma,y)>=r+1`, and put `q=d(z,y)`.  Because `H` has the sole attachment
`z`,

    q+d_K(z,sigma)=d(y,sigma)>=r+1.

Also `d_K(z,sigma)<=delta`, so

    q>=r+1-delta>=h+1.                                  (1)

The realizer `x` is not in `H`, since every vertex of `H` has `z` as its
only possible nearest cycle anchor while `z!=m`.  For every center `c`
outside `H`, sole attachment gives

    d(y,c)=q+d(z,c).

Moreover `e<=d(x,c)<=h+1+d(z,c)`, so `d(z,c)>=delta-1`.
Together with (1), `d(y,c)>=e`.  Therefore, if `H` contains no center,
`d(y,C)=e` and `y` is an `e`-realizer of height `q>h`, contradicting the
choice of `x`.

Consequently an adjacent deletion root can be spoiled by a sole-attachment
covering component only if that component contains a center.  If both
neighbors are spoiled, their two distinct components contain centers
`c_-`,`c_+`; the same estimate gives `d(z_-,c_-),d(z_+,c_+)>=delta-1`, hence

    d(c_-,c_+) >= (delta-1)+2+(delta-1)=2 delta,

and therefore `r>=2 delta`.

This reduction is exact.  In 352 residual corpus graphs, selecting a
maximum-height realizer made one of the two adjacent roots satisfy WN2 in
every case.

## Remaining proof obligation

What is not proved is the active-component surplus bound needed to sum the
cover capacities, together with the center-containing adjacent component
case when `r>=2 delta`.  No counterexample to either local bound was found,
but treating their finite verification as a proof would be invalid.
