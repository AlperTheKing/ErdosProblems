You are tasked with resolving Erdős Problem 114, the
Erdős--Herzog--Piranian polynomial lemniscate conjecture.

For an integer n >= 1 and a monic polynomial p in C[z] of degree n, let

    L(p) = H^1({z in C : |p(z)| = 1}),

where H^1 denotes one-dimensional Hausdorff measure. Prove that

    L(p) <= L(z^n - 1)

for every n and every such p.

The immediate route is deliberately narrow. Terence Tao proved the assertion
for all sufficiently large n in arXiv:2512.12455, while rigorous small-degree
work is reported through n = 14. Extract a completely explicit threshold N0
from Tao's proof and close every degree 15 <= n < N0 by a complete rigorous
argument or independently replayable interval certificate.

A complete resolution must include:

1. a dependency ledger for every constant and threshold used in the
   high-degree theorem;
2. a numerical N0 and exact inequalities proving all n >= N0;
3. a complete proof or rigorous certificate for every remaining degree;
4. independent replay of all computational certificates; and
5. a current novelty/status check before any discovery claim.

The following do not count as a resolution: restating "sufficiently large";
an ineffective or unspecified constant; a floating-point plot; checking only a
subfamily of polynomials; a local-maximality result; an asymptotic estimate; a
finite computation without completeness; or a proof that leaves even one
degree untreated.

Start with independent source audits. Preserve incompatible readings until the
quantitative dependency ledgers have been compared. Search aggressively for:
hidden compactness arguments, qualitative o(1) terms, non-explicit stability
constants, equality cases, strict-versus-nonstrict inequalities, topology
changes of the lemniscate, and interval-boundary failures.

Every active approach must state its exact deliverable, current frontier,
logical bridge, next falsifiable action, and exit condition. If the source
contains an ineffective dependency or the remaining finite interval has no
complete certification method, stop this route and identify that exact gap.
Do not manufacture further asymptotic reformulations.

Use all available multiagent slots for independent proof extraction and
adversarial refereeing. Use CPU computation only after the mathematical
reduction, interval semantics, and completeness argument pass calibration.
