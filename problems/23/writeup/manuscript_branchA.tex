\subsection{Branch A: the length-five reduction to C5-RS}

Branch A treats bad edges whose certified shortest rows have length \(5\).  Fix a bad edge \(f \in M\) with
\[
\ell(f)=5,
\]
and fix a certified shortest row
\[
Q=(q_0,q_1,q_2,q_3,q_4)\in \operatorname{cyc}(f).
\]
The four consecutive edges of \(Q\) are blue edges, and the closing edge \(q_4q_0\) is the bad edge \(f\).

The local Branch-A object is the all-length-five positive \(K\)-component generated by \(Q\).  The row loads on \(Q\) are denoted
\[
s_i=s(q_i),\qquad i\in \mathbb Z/5\mathbb Z.
\]
The active threshold is
\[
\tau=\frac{5m}{N}.
\]
Throughout the paper,
\[
\eta=\frac{N^2-25m}{25}.
\]

The Branch-A row-side target is the following \(C_5\) row-sum estimate.

\[
\text{\bf C5-RS.}\qquad
\sum_{i\in\mathbb Z/5\mathbb Z}(s_i-\tau)_+
\le
\left(1+\frac{25}{N}\right)\eta,
\]
where
\[
(x)_+=\max(x,0).
\]

This estimate is sharp on the balanced blowups of \(C_5\).  In those examples \(\eta=0\), the five row loads are exactly at the active threshold, and both sides vanish.

We next recall why C5-RS implies the length-five GERSH bound.  Use the uniform width choice
\[
w_i=\frac N5,\qquad i=0,\ldots,4.
\]
The net-DW assembly gives
\[
I(Q)\le \sum_{i=0}^4 \max(s_i,\tau).
\]
The elementary identity used in this assembly is
\[
\sum_{i=0}^4 \max(s_i,\tau)
=
5\tau+\sum_{i=0}^4(s_i-\tau)_+.
\]
Since
\[
5\tau=\frac{25m}{N}
\]
and
\[
\frac{25\eta}{N}
=
\frac{N^2-25m}{N}
=
N-\frac{25m}{N},
\]
C5-RS gives
\[
\sum_{i=0}^4 \max(s_i,\tau)
\le
\frac{25m}{N}
+
\left(1+\frac{25}{N}\right)\eta.
\]
Expanding
\[
\left(1+\frac{25}{N}\right)\eta
=
\eta+\frac{25\eta}{N},
\]
the right-hand side becomes
\[
\frac{25m}{N}
+
\eta
+
\left(N-\frac{25m}{N}\right)
=
N+\eta.
\]
Therefore
\[
I(Q)\le N+\eta.
\]
Since \(Q\in\operatorname{cyc}(f)\) was arbitrary, C5-RS implies
\[
\operatorname{ROWSUM}(f)\le N+\eta
\]
for every bad edge \(f\) of length \(5\).

It remains to prove C5-RS.  Define the active mask
\[
P=\{i\in \mathbb Z/5\mathbb Z:s_i>\tau\}.
\]
Branch A uses the following mask trichotomy.

First suppose
\[
P=\varnothing.
\]
Then
\[
\sum_i(s_i-\tau)_+=0.
\]
Thus C5-RS follows immediately once the scalar input
\[
\eta\ge 0
\]
has been established.  In the pure all-length-five case this input is supplied by Bank0, which proves
\[
N^2-25m\ge0.
\]
If the graph contains a longer positive row, the same scalar input is supplied by Bank-L.  Thus the empty-mask case uses only the already-established field
\[
\texttt{etaNonneg}:\quad \eta\ge0.
\]
It does not use an empty-mask cone certificate.

Second suppose that \(P=A\) is a nonempty proper mask:
\[
\varnothing\ne A\subsetneq \mathbb Z/5\mathbb Z.
\]
Set
\[
X(A)=\sum_{i\in A}(s_i-\tau).
\]
The six A1 proper-mask cone certificates prove
\[
X(A)\le
\left(\frac{25}{N}+\frac23\right)\eta.
\]
These certificates are applied only after the scalar input \(\eta\ge0\) is available.  Since
\[
\eta\ge0
\]
implies
\[
\frac23\eta\le \eta,
\]
the A1 estimate lifts to
\[
X(A)\le
\left(\frac{25}{N}+1\right)\eta.
\]
For the active mask \(P=A\),
\[
\sum_i(s_i-\tau)_+=X(A).
\]
Hence C5-RS follows in every nonempty proper-mask case.

Third suppose
\[
P=\mathbb Z/5\mathbb Z.
\]
Then every row vertex is active.  This is the full-mask case.  It is discharged by ODL, which proves directly
\[
I(Q)\le N+\eta.
\]
Equivalently, it is the full-mask instance of the C5-RS assembly.  The ODL seed tree routes this case to the ordered-door-layer certificates and the finite quotient seed certificates.

Thus the Branch-A length-five proof is:
\[
P=\varnothing
\quad\Longrightarrow\quad
\eta\ge0\text{ supplies C5-RS};
\]
\[
\varnothing\ne P\subsetneq \mathbb Z/5\mathbb Z
\quad\Longrightarrow\quad
\text{A1 proper-mask cones plus }\eta\ge0;
\]
\[
P=\mathbb Z/5\mathbb Z
\quad\Longrightarrow\quad
\text{ODL}.
\]

The logical order is important.  First, the scalar field
\[
\eta\ge0
\]
is supplied externally: by Bank0 if all bad edges have length \(5\), or by Bank-L if some positive row has length greater than \(5\).  Second, the A1 proper-mask cones or the ODL full-mask certificate are applied.  Third, C5-RS is assembled.  Finally, the uniform-width net-DW assembly gives
\[
I(Q)\le N+\eta.
\]

All three mask branches use only the standing hypotheses: \(B\) is a maximum cut, \(B\) is \(\Gamma\)-minimal among \(B\)-connected maximum cuts, \(G\) is triangle-free, and every bad edge has length \(5\).  Bank0 is the scalar-bank source in the pure all-length-five case; Bank-L is the scalar-bank source whenever a longer positive row exists.
