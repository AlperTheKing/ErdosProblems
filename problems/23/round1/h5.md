## 1. The pipeline and its calibration

`h5_core.py` implements three independent max-cut routes and one certifier:

| route | applicability | role |
|---|---|---|
| `maxcut_exhaustive` | N ≤ 26 | ground truth |
| `maxcut_cpsat_xor` | any N | `s_v ∈ {0,1}`, `c_uv ≤ s_u+s_v`, `c_uv ≤ 2−s_u−s_v`, maximise Σc |
| `maxcut_cpsat_metric` | any N | metric-polytope model: `y_uv ∈ {0,1}` with all four triangle inequalities per triple |

`certify()` always (i) verifies triangle-freeness explicitly on the final object,
(ii) feeds CP-SAT a heuristic incumbent as a hint **and** as a lower-bound constraint,
(iii) **re-derives the 2-colouring from the solver's variables and re-counts crossing edges
directly**, so the reported max cut is never taken on the solver's word, and (iv) records
`BestObjectiveBound` so that even a timeout yields a valid `bip ≥ m − dual_bound`.

## 3. Why 90 / 100 / 210 / 225 are hard ceilings: the C5-colourability lemma

**Lemma.** *If a triangle-free graph G on N vertices admits a homomorphism to C₅, then*
`bip(G) ≤ B(N) := max{ min_i w_i w_{i+1} : w ∈ ℤ⁵_{≥0}, Σw_i = N }`.

*Proof.* Let φ : V(G) → ℤ₅ be the homomorphism and w_i = |φ⁻¹(i)|. Every edge of G joins
consecutive fibres, so G is a **subgraph** of the blow-up C5[w]. Deleting an edge decreases
the number of monochromatic edges of every fixed cut by 0 or 1, so `bip` is monotone under
edge deletion; hence bip(G) ≤ bip(C5[w]). Finally, in a blow-up the max cut never splits a
part: with all other vertices fixed, the cut value is a **linear** function of how many
vertices of the independent set V_i lie on side A, so an optimum exists at a vertex of the
box, i.e. with every part unsplit. Therefore bip(C5[w]) = min_i w_i w_{i+1} ≤ B(N). ∎

`h5_c5bound.py` computes B(N) exactly:

| N | 49 | 50 | 51 | 73 | 74 | 76 | 78 |
|---|---|---|---|---|---|---|---|
| floor(N²/25) | 96 | 100 | 104 | 213 | 219 | 231 | 243 |
| **B(N)** | **90** | **100** | **100** | **210** | **210** | **225** | **240** |
| parts | (9,10,9,10,11) | (10⁵) | (10,10,10,10,11) | (14,15,14,15,15) | (14,15,14,15,16) | (15,15,15,15,16) | (15,16,15,16,16) |

Closed forms confirmed by the sweep: `B(5n)=n²`, `B(5n±1)=n²` / `n²−n`, `B(5n+2)=n²`,
`B(5n+3)=n(n+1)`.

**Consequence: every counterexample to Erdős #23 must be non-C5-colourable.** In particular
(Andrásfai–Erdős–Sós) it cannot have minimum degree > 2N/5, since that forces bipartiteness;
and the classical minimum-degree stability results push any counterexample well below the
2N/5 regime where the blow-ups live. This is what turned the search into a targeted one.

## 4. Exhaustive search of the blow-up world

Because max cuts of blow-ups never split parts, `bip(H[w])` is *exactly*
`min over the 2^(h−1) unsplit 2-colourings of Σ_{same-side edges} w_a w_b` — no solver needed.
`h5_blowup.cpp` (C++17, `std::thread`, C5-seeded steepest-ascent hill climbing on unit weight
transfers, with early-exit trial evaluation) searches this exactly.

```
clang++ -O3 -march=native -std=c++17 h5_blowup.cpp -o h5_blowup.exe
geng.exe -tc -q h              # h = 5..12 ; -d4/-d5/-d6 for h = 13..17
H5_THREADS=58 ./h5_blowup.exe 49 51 74 76 < tf_11.g6
```

## 5. The decisive experiment: the non-C5 gain does not scale

`a(12) = 5 > B(12) = 4` proves that non-C5-colourable graphs *can* beat the blow-up ceiling.
The whole question is **by how much, and does it grow?** Define `gain_H(N) = max_w bip(H[w]) − B(N)`.

`h5_gain.py` / `h5_blowup.exe` measured this for every classical dense non-C5-colourable
triangle-free base (Grötzsch = Myc(C5), Mycielskian of C7, Clebsch = folded 5-cube, Petersen,
Andrásfai And(3)…And(7), circulants C13(1,5), C16(1,4,7), and the exact record graphs at
N = 12, 13, 14 used as bases):

```
Grotzsch : gain = +1 at N = 12, 17;  0 at N = 22,27,32,37,42,47,49,51,52,57,62,74,76
rec_N12  : gain = +1 at N = 17, 32, 47, 52;  0 at N = 49, 51, 74, 76
rec_N14  : gain = +1 at N = 14, 17, 27;      0 at N = 49, 51, 74, 76
Petersen, Clebsch, Myc(C7), And(3..7), C16(1,4,7): gain = 0 at every N >= 17
```

Two facts, both robust across every base tested:

1. **The gain never exceeds +1**, anywhere, at any N, for any base.
2. **The gain only ever fires at N ≡ 2 (mod 5)** — precisely the residue where B(N) = n² sits
   furthest below floor(N²/25). At N ≡ ±1 (mod 5) — which is exactly where the assigned
   targets 49, 51, 74, 76 live — **the gain is identically zero**.

At every N ≥ 32 the optimal weight vector collapses onto a single induced C5 of the base
(e.g. Grötzsch at N = 49 returns `w = [9,10,11,9,10,0,0,0,0,0,0]`), i.e. the extra
non-C5 structure is *worthless* asymptotically. The +1 gains come from spread weight vectors
with all classes of size ≈ 2–5, and they die once B(N) grows past ≈ 36.

The Andrásfai blow-ups deserve a separate note: by Chen–Jin–Koh/Łuczak-type stability,
triangle-free graphs of large minimum degree are homomorphic to some And(k), and And(2) = C5.
Since **And(3), And(4), …, And(7) blow-ups never exceed B(N)** (they only ever reach it, by
concentrating on an induced C5), the entire "large minimum degree" regime is closed off.

## 6. General search (no structural assumption)

`h5_hunt.cpp` — simulated annealing over triangle-free graphs on N ≤ 64 with an
**adversarial pool of 384 cuts** as objective. The objective `min over pool of monochromatic
edges` is an *upper* bound on bip, so it can only over-report; the pool is refreshed every
8192 moves by a multi-restart max-cut local search that inserts the most binding cut it
finds, and every reported graph is re-certified by CP-SAT.

```
clang++ -O3 -march=native -std=c++17 h5_hunt.cpp -o h5_hunt.exe
./h5_hunt.exe 49 1500 30 10,10,10,10,9
./h5_hunt.exe 51 1500 28 11,10,10,10,10
python h5_certify_g6.py @h5_hunt_winners.g6 900 xor
```

Smoke tests: recovers a(12) = 5, a(13) = 6, a(15) = 9, a(16) = 9 (misses a(14) = 7 → 6).

Results, both **re-certified exactly**:

```
N=49  m=480  maxcut=390 OPTIMAL  bip=90   ratio 0.0374844   (= B(49))
N=51  m=520  maxcut=420 OPTIMAL  bip=100  ratio 0.0384468   (= B(51))
```

The annealer, seeded at the blow-up and from random triangle-free graphs, never left the
blow-up value. Runs at N = 17…24 (where the required excess is far smaller, see §7) also
never exceeded B(N); in particular a 300 s / 8-thread run at N = 18 returns exactly 12 = B(18).

## 7. A correction to the targeting heuristic (the main thing I leave behind)

The brief selects targets by minimising `frac(N²/25)`, which is 0.04 at N ≡ ±1 (mod 25).
That is the wrong metric. What a construction actually achieves is B(N), not N²/25, so the
right quantity is

```
need(N) = floor(N^2/25) + 1 - B(N)     ( = the excess over the C5-colourable world required )
```

`h5_needgain.py` tabulates it. The residue classes behave completely differently:

| N mod 5 | B(N) | N²/25 − B(N) | need(N) grows like |
|---|---|---|---|
| 0 | n² | 0 | **1** (constant!) |
| **3** | n(n+1) | 0.2n + 0.36 | **≈ 0.04 N** |
| 1 | n² | 0.4n + 0.04 | ≈ 0.08 N |
| 4 | n²−n | 0.6n + 0.64 | ≈ 0.12 N |
| 2 | n² | 0.8n + 0.16 | ≈ 0.16 N |

So among unverified orders the required excess is:

```
N=18  need=1     N=48  need=3     N=53  need=3     N=58  need=3
N=16  need=2     N=63  need=3     N=68  need=3     N=73  need=4   N=78  need=4
N=21  need=2     N=23  need=2     N=28  need=2     N=33  need=2   N=38 need=2  N=43 need=2
...
N=51  need=5     N=49  need=7     N=76  need=7     N=74  need=10
```

**The assigned N ≡ ±1 (mod 25) orders are among the *worst* places to look**, needing an
excess of 5–10, while the observed maximal excess anywhere is +1. Conversely
`N ≡ 3 (mod 5)` needs only ≈ 0.04 N, and `N = 18` needs a single unit — the exact size of gain
that demonstrably occurs at N = 12, 14, 17, 27, 32, 47, 52.
