# Erdős #23 — Family F4 (induction with a potential): findings

`bip(G) = |E(G)| − maxcut(G)`; conjecture: `bip(G) ≤ N²/25` for triangle-free `G` on `N` vertices.
All computations below are exact (integers / `Fraction`); no floating point on any acceptance path.
Scripts are in this directory and named in each section.

Answers to the three questions posed to family F4: **(i)** the naive step is false — smallest witness `C5`, and it fails on the whole extremal family `C5[n]` by the factor `5/2` (R5, exact census in §5); **(ii)** any potential that repairs it is pinned to `N²/25` along a chain and must jump by `3N/25` on a single deletion (R6); **(iii)** peeling `N[v]` is not merely insufficient, it is strictly worse than deleting one vertex (R7), and it destroys `bip` completely on `C5[n]` while releasing only `64%` of the needed budget.

## 1. R1 — the blow-up reduction lemma

For a graph `H` on vertex set `[h]` and `a ∈ Z^h_{≥0}`, `H[a]` denotes the blow-up: blob `V_u` of `a_u`
independent vertices for each `u`, complete join between `V_u` and `V_v` whenever `uv ∈ E(H)`.
`H[a]` is triangle-free iff `H` is.

> **Lemma A.** For every loopless graph `H` and every `a ∈ Z^h_{≥0}`,
> ```
> bip(H[a]) = min_{S ⊆ V(H)}  Σ_{uv ∈ E(H) with |{u,v} ∩ S| ≠ 1}  a_u a_v .
> ```
> That is: among all bipartitions of `H[a]` it is optimal to keep every blob undivided.

*Proof.* Let `(A,B)` be a bipartition of `V(H[a])` and put `x_u = |A ∩ V_u| ∈ [0, a_u]`. Blobs are
independent and consecutive blobs are completely joined, so the monochromatic (= uncut) edges are
exactly, for each `uv ∈ E(H)`, the `x_u x_v` pairs inside `A` and the `(a_u−x_u)(a_v−x_v)` pairs inside
`B`. Hence
```
bip(H[a]) = min { F(x) : x ∈ Z^h, 0 ≤ x_u ≤ a_u },
F(x) = Σ_{uv∈E(H)} [ x_u x_v + (a_u−x_u)(a_v−x_v) ].
```
Because `H` has no loops, `F` contains no square term `x_u²`: it is **affine in each variable
separately**. Let `x*` minimise `F` over the *real* box `Π_u [0,a_u]` (compact, so a minimiser exists).
Freeze all coordinates but `x_1`: `F` is affine in `x_1`, so moving `x_1` to `0` or to `a_1` does not
increase `F`. Repeating for `u = 1,…,h` produces `x° ∈ Π_u {0, a_u}` with `F(x°) ≤ F(x*)`. Thus the
real minimum is attained at a vertex of the box, which is an integer point, so the integer and real
minima coincide and are attained at some `x°`. Writing `S = {u : x°_u = a_u}`, the term of `uv` equals
`a_u a_v` when `u,v` are both in `S` or both outside `S`, and `0` otherwise. ∎

*Verification.* `f1_check_lemmaA.py` compares the formula against brute-force `bip` of the explicitly
constructed blow-up for **all** triangle-free `H` on `≤ 5` vertices and random weights: `2577` exact
comparisons, `0` mismatches; also `bip(H[t,…,t]) = t² bip(H)`, `0` mismatches.

> **Corollary A1.** `bip(C5[a₁,…,a₅]) = min_{i∈Z₅} a_i a_{i+1}`.

*Proof.* Every cut of a graph meets every cycle in an even number of edges, so a cut of `C5` leaves an
odd number (`1`, `3` or `5`) of edges uncut — in particular at least one, whence the min in Lemma A is
`≥ min_i a_i a_{i+1}`. Conversely `S = {j+2, j+4}` leaves exactly the edge `{j,j+1}` uncut (the two
elements of `S` are non-adjacent, and its complement `{j, j+1, j+3}` spans only the edge `{j,j+1}`),
giving `≤ a_j a_{j+1}` for each `j`. ∎

> **Corollary A2.** If `Σ a_i = N` then `bip(C5[a]) ≤ ⌊N²/25⌋`, with equality iff `5 | N` and
> `a = (N/5,…,N/5)`.

*Proof.* Put `m = min_i a_i a_{i+1}`. Then `m⁵ ≤ Π_{i∈Z₅} a_i a_{i+1} = (Π_i a_i)²`, and by AM–GM
`Π a_i ≤ (N/5)⁵`, so `m⁵ ≤ (N/5)^{10}`, i.e. `m ≤ (N/5)²`; `m` is an integer, so `m ≤ ⌊N²/25⌋`.
Equality in AM–GM forces all `a_i` equal. ∎

> **Theorem B.** If a graph `G` on `N` vertices admits a homomorphism to `C5`, then
> `bip(G) ≤ ⌊N²/25⌋`, with equality iff `5 | N` and `G ≅ C5[N/5]`.

*Proof.* A homomorphism `φ : G → C5` splits `V(G)` into independent classes `V_i = φ^{-1}(i)` with edges
only between consecutive classes, so `G` is a spanning subgraph of `C5[a]`, `a_i = |V_i|`. Deleting
edges cannot increase `bip` (the uncut set of any fixed bipartition only shrinks), so
`bip(G) ≤ bip(C5[a]) ≤ ⌊N²/25⌋` by A1, A2. For equality, A2 forces `a_i = N/5` for all `i`; moreover
the cut `S = {i+2, i+4}` shows `bip(G) ≤ e_G(V_i, V_{i+1})` for every `i`, so equality forces
`e_G(V_i,V_{i+1}) = (N/5)²` for all `i`, i.e. `G = C5[N/5]`. ∎

> **Theorem C (high minimum degree).** Every triangle-free `G` with `δ(G) > ⌊3N/8⌋` satisfies
> `bip(G) ≤ ⌊N²/25⌋`, with equality iff `G ≅ C5[N/5]`.

*Proof.* By Häggkvist's theorem (1982) every triangle-free graph with `δ > ⌊3n/8⌋` is homomorphic to
`C5`; apply Theorem B. ∎
(The threshold `3N/8` is sharp for the hypothesis: the Andrásfai graph `A₃ = ` Wagner graph `V₈` has
`δ = 3n/8` and is not homomorphic to `C5`; note however `bip(V₈[n]) = 2n² = N²/32 < N²/25` by Lemma A,
so it is not a threat to the conjecture.)

## 2. R4 — the exact one-vertex deletion step

> **Lemma D.** For every graph `G` and vertex `v`: `bip(G) − bip(G−v) ≤ ⌊d(v)/2⌋`, and this is tight
> (equality for every vertex of `C5[n]`).

*Proof.* Take an optimal bipartition of `G−v` and insert `v` on the side containing fewer of its
neighbours: at most `⌊d(v)/2⌋` new monochromatic edges appear, so `bip(G) ≤ bip(G−v) + ⌊d(v)/2⌋`.
Tightness: for `v ∈ C5[n]`, `d(v) = 2n` and by A1 `bip(C5[n]) − bip(C5[n]−v) = n² − n(n−1) = n`. ∎

**Deficiency form of the step.** Put `D(G) := N²/25 − bip(G)` (the conjecture is `D ≥ 0`). Then
```
bip(G) ≤ bip(G−v) + (2N−1)/25   ⟺   D(G−v) ≤ D(G).
```
So *the naive induction step asks for a vertex whose deletion does not increase the deficiency.*
This is the sharpest way to state what has to be found, and §3 shows the extremal graphs are strict
local minima of `D`.

## 3. R5 — the naive step is false, and exactly how badly

Define `ρ(G) = min_v (bip(G) − bip(G−v))` and `ρ(N) = max { ρ(G) : G triangle-free, |V(G)| = N }`.
The naive step holds for `G` iff `25·ρ(G) ≤ 2N−1`.

> **Theorem E.**
> (a) `ρ(N) ≤ ⌊½⌊2N/5⌋⌋ ≤ ⌊N/5⌋` for every `N`.
> (b) `ρ(5n) = n` for every `n ≥ 1`, attained by `C5[n]` at **every** vertex.
> (c) Consequently, for every `n` the graph `C5[n]` fails the naive step at every vertex, with
> `actual/budget = 25n/(10n−1) → 5/2`; and `5/2` is the worst possible loss, by (a).

*Proof.* (a) If `G` is bipartite then `ρ(G) = 0`. Otherwise `G` is triangle-free and non-bipartite, so
by Andrásfai–Erdős–Sós `δ(G) ≤ 2N/5`; take `v` of minimum degree and apply Lemma D.
(b) `C5[n]` is vertex-transitive and `bip(C5[n]) − bip(C5[n]−v) = n² − n(n−1) = n` by A1; and
`⌊½⌊2·5n/5⌋⌋ = n`. (c) Budget `= (2N−1)/25 = (10n−1)/25`. ∎

**Exhaustive census** (`f4_step.cpp` → `f4_step.exe`, input `geng -q -t -c N`; exact `bip` by
`2^N`-subset enumeration with an `f[S] = #edges inside S` table; `ρ(G)` from `min_v bip(G−v)`):

```

N=6  graphs=19      maxρ=0  budget=11/25   0

N=8  graphs=267     maxρ=1  budget=15/25   7     G?`F`w …
N=9  graphs=1380    maxρ=1  budget=17/25   14    H?AFBo] …
N=10 graphs=9832    maxρ=2  budget=19/25   61    I?rFf_{N? = C5[2]   (unique maximiser)
N=11 graphs=90842   maxρ=2  budget=21/25   922   J?bFF`wN?{? = Cayley(Z₁₁,±{1,3})
N=12 graphs=1144061 maxρ=1  budget=23/25   8849  K???C@?kA]fs …
```
(counts are of connected graphs; for disconnected `G`, `ρ(G) = min over components`, so nothing is
lost). Since `⌊(2N−1)/25⌋ = 0` for `N ≤ 12`, "the step holds" means "some vertex can be deleted for
free"; the last column counts the graphs where *every* vertex fails. **The smallest triangle-free
graph on which every vertex fails the naive step is `C5` itself** (unique on `5` vertices; there is
none on `≤ 4` vertices because triangle-free graphs on `≤ 4` vertices are bipartite).

Two remarks from the census:
* the `N = 10` maximiser is exactly `C5[2]` (verified isomorphic, `f4_blowup.py`), matching Theorem E(b);
* the `N = 11` maximiser is **not** a `C5`-blow-up: it is the circulant `C₁₁(1,3) = Cayley(Z₁₁, ±{1,3})`,
  `4`-regular (exactly at the Andrásfai–Erdős–Sós bound `δ ≤ ⌊2N/5⌋ = 4`), `bip = 4`, `ρ = 2`
  (`f4_id11.py`). So the extremal behaviour for the *step* is not confined to blow-ups of `C5`.

Exact maxima `a_N = max bip` over triangle-free graphs (`census.exe`, exhaustive):
`a₅..a₁₃ = 1, 1, 1, 2, 2, 4, 4, 5, 6`; all `≤ ⌊N²/25⌋`, tight at `N = 5, 10`
(`a₁₀ = 4` attained **only** by `C5[2]`; `a₁₃ = 6 < 6.76`).

## 4. R6 — what any repairing potential is forced to look like

> **Proposition F (rigidity).** Let `Φ` be any real-valued function on triangle-free graphs with
> (a) `Φ(G) ≥ bip(G)`; (b) `Φ(G) ≤ |V(G)|²/25`; (c) for every non-empty `G` there is a vertex `v`
> with `Φ(G) − Φ(G−v) ≤ (2N−1)/25`.
> Then for every `n`: `Φ(C5[n]) = n²`, and there is a chain of induced subgraphs
> `C5[n] = G_{5n} ⊃ G_{5n−1} ⊃ … ⊃ G_0 = ∅` with `Φ(G_M) = M²/25` for **every** `M`.
> In particular, for the vertex `v` selected by (c) at `G = C5[n]`,
> ```
> Φ(C5[n]−v) − bip(C5[n]−v) = (5n−1)²/25 − n(n−1) = 3n/5 + 1/25 = 3N/25 + 1/25 .
> ```

*Proof.* `bip(C5[n]) = n² = (5n)²/25`, so (a)+(b) squeeze `Φ(C5[n]) = n²`. If `v` is the vertex given by
(c) for a graph `G` with `Φ(G) = N²/25`, then `Φ(G−v) ≥ N²/25 − (2N−1)/25 = (N−1)²/25 ≥ Φ(G−v)` by (b),
so `Φ(G−v) = (N−1)²/25`; iterate. The displayed identity uses `bip(C5[n]−v) = n(n−1)` (Cor. A1). ∎

Consequences (all exact):

1. **No potential of the form `Φ = bip + (correction)` with correction `= o(N)` can work.** The
   correction must be `0` on `C5[n]` (forced by (a)+(b)) and `≥ 3N/25 + 1/25` on `C5[n] − v`: a single
   vertex deletion from the extremal graph must move it by at least `3N/25`.
2. **No `Φ` vanishing on bipartite graphs can work.** Take `G = C5`: `Φ(C5) = 1`, every `C5−v = P₄` is
   bipartite, so (c) would need `1 − 0 ≤ 9/25`.
3. `Φ` must be *tight* (`= M²/25`) on a full chain of `N+1` graphs, i.e. it can carry no slack anywhere
   along the induction; proving `Φ ≤ M²/25` for those graphs is then exactly as hard as the tight cases
   of the conjecture itself. In this precise sense the one-vertex potential route is forced to be
   circular.

## 5. R7 — independent-neighbourhood peeling, quantified

`N(v)` is independent because `G` is triangle-free, so re-inserting `N[v]` is cheap to bound:

> **Lemma G.** For every vertex `v` of a triangle-free `G`,
> ```
> bip(G) ≤ bip(G − N[v]) + ½ · e(N(v), V∖N[v]) = bip(G − N[v]) + ½ ( Σ_{u∈N(v)} d(u) − d(v) ).
> ```

*Proof.* Take an optimal bipartition `(A,B)` of `G − N[v]`. Put **all** of `N(v)` on the side receiving
fewer of the `e(N(v), V∖N[v])` edges, and `v` on the other side. No edge inside `N(v)` (independent),
no uncut edge between `v` and `N(v)` (opposite sides), and at most half of `e(N(v), V∖N[v])` uncut. ∎
(This beats the per-vertex greedy bound `Σ_{u∈N(v)}⌊(d(u)−1)/2⌋ + ⌊d(v)/2⌋` by the term `d(v)/2`.)

> **Theorem H (peeling on the sharp family).** For `G = C5[n]` and any `v`: `G − N[v]` is
> `K_{n,n} ∪ (n−1)K₁`, hence `bip(G−N[v]) = 0`, while `N' = |V| − 1 − d(v) = 3n−1`. The peeling step
> `bip(G) ≤ bip(G−N[v]) + (N² − N'²)/25` therefore fails by exactly
> ```
> n² − (16n² + 6n − 1)/25 = (3n−1)²/25 = N'²/25 .
> ```
> The peel destroys `100%` of `bip` while releasing only `(16n²+6n−1)/25 = 0.64·n²(1+o(1))` of budget:
> the shortfall equals the *entire* budget of the surviving graph.

*Proof.* `v ∈ V₁`, `N(v) = V₂ ∪ V₅`, so `G − N[v]` is induced on `V₁∖{v} ∪ V₃ ∪ V₄`, and only `V₃V₄` is
an edge of `C5` there; by A1 (with `a = (n−1,0,n,n,0)`) `bip = 0`. Arithmetic as displayed; verified in
`f4_blowup.py` for `n ≤ 8`. ∎

> **Corollary I (peeling is strictly worse than deleting one vertex).** For `d`-regular triangle-free `G`
> the peeling step is guaranteed by Lemma G only when `25 d(d−1) ≤ 2(d+1)(2N−d−1)`, i.e.
> `d ≤ 4N/27 + O(1)`, whereas the one-vertex step is guaranteed when `⌊d/2⌋ ≤ (2N−1)/25`, i.e.
> `d ≤ 4N/25 + O(1)`. Since `4/27 < 4/25`, removing a whole closed neighbourhood covers a **strictly
> smaller** degree range than removing a single vertex.

So the answer to (iii) is negative and quantitative: the extra vertices removed by a peel buy budget
`(d+1)(2N−d−1)/25` which grows linearly in `d`, but the edges destroyed grow like `d²/2`; the crossover
is at `d ≈ 4N/27`, below the `4N/25` of the trivial step, and both are far below the `δ = 2N/5` of the
extremal graphs.

## 6. R8 — the block-of-five theorem (the only scale at which the step is not already dead)

For `W ⊆ V` write `cost(W) = bip(G) − bip(G−W)`; the induction budget for `|W| = k` is
`(N² − (N−k)²)/25 = k(2N−k)/25`.

> **Theorem J.** Let `G = C5[n]`, `N = 5n`, `1 ≤ k ≤ 5n`, `k = 5q + r` with `0 ≤ r ≤ 4`. Then
> ```
> min_{|W|=k} cost(W) = n² − v(n,k),   v(n,k) = (n−q)²        if r = 0,
>                                              (n−q)(n−q−1)   if r ∈ {1,2},
>                                              (n−q−1)²       if r ∈ {3,4}.
> ```
> The step `min_{|W|=k} cost(W) ≤ k(2N−k)/25` holds **iff `5 | k`**, and for `k = 5s` it holds with
> **equality**: `cost = budget = 2ns − s²`. For `k ≢ 0 (mod 5)` the failure margins are exactly
> ```
> r = 1 : (3/5)(n−q) + 1/25      r = 2 : (1/5)(n−q) + 4/25
> r = 3 : (4/5)(n−q) − 16/25     r = 4 : (2/5)(n−q) − 9/25          (all > 0 since n − q ≥ 1)
> ```

*Proof.* Induced subgraphs of `C5[n]` on `5n−k` vertices are exactly the `C5[a]` with `0 ≤ a_i ≤ n`,
`Σa_i = 5n−k`; write `d_i = n − a_i ≥ 0`, `Σ d_i = k`. By A1 the surviving `bip` is
`min_i (n−d_i)(n−d_{i+1})`, so `min_W cost = n² − max_d min_i (n−d_i)(n−d_{i+1})`.

*Upper bound for `v(n,k)`.* `Σ_{i∈Z₅}(d_i + d_{i+1}) = 2k`, so some `i` has
`d_i + d_{i+1} ≥ ⌈2k/5⌉ = 2q + ⌈2r/5⌉`. With a fixed sum, a product `(n−x)(n−y)` is largest when
`x, y` are as equal as possible, so for that `i`:
`r = 0`: sum `≥ 2q` ⟹ product `≤ (n−q)²`;
`r ∈ {1,2}`: `⌈2r/5⌉ = 1`, sum `≥ 2q+1` ⟹ product `≤ (n−q)(n−q−1)`;
`r ∈ {3,4}`: `⌈2r/5⌉ = 2`, sum `≥ 2q+2` ⟹ product `≤ (n−q−1)²`.
*Attainment.* `r=0`: `d ≡ q`. `r=1`: `d = (q+1,q,q,q,q)`. `r=2`: `d = (q+1,q,q+1,q,q)` (the two
increments non-adjacent). `r=3`: `d = (q+1,q+1,q+1,q,q)`. `r=4`: `d = (q+1,q+1,q+1,q+1,q)`. In each case
the minimum product equals the bound.

*Step condition.* With `budget = k(10n−k)/25`:
`k = 5q`: `cost = n²−(n−q)² = 2nq−q²` and `budget = 5q(10n−5q)/25 = 2nq−q²` — equality.
`r = 1`: `cost = 2nq+n−q²−q`, `budget = 2nq−q²−(2/5)q+(2/5)n−1/25`, difference `(3/5)(n−q)+1/25 > 0`.
`r = 2`: same `cost`, `budget = 2nq−q²−(4/5)q+(4/5)n−4/25`, difference `(1/5)(n−q)+4/25 > 0`.
`r = 3`: `cost = 2n(q+1)−(q+1)²`, `budget = 2nq−q²−(6/5)q+(6/5)n−9/25`, difference `(4/5)(n−q)−16/25`.
`r = 4`: same `cost`, `budget = 2nq−q²−(8/5)q+(8/5)n−16/25`, difference `(2/5)(n−q)−9/25`.
When `r ≥ 1` and `k ≤ 5n` we have `q ≤ n−1`, i.e. `n−q ≥ 1`, so the last two differences are
`≥ 4/5−16/25 = 4/25 > 0` and `≥ 2/5−9/25 = 1/25 > 0`. ∎

*Verification.* `f4_kstep.py` recomputes `v(n,k)` by exhaustive search over deficit vectors and checks
the step for all `n ≤ 12`, `1 ≤ k ≤ 5n`: formula mismatches `0`; the set of `k` for which the step
closes is exactly `{5,10,…,5n}` for every `n ≤ 12`, always with equality.

**Reading.** The extremal family has period `5`; the induction must move in blocks of `5` vertices, and
even then there is *no slack at all* — the sharp family sits at equality for every block count `s`.
The corresponding target statement is

> **(★)** every triangle-free `G` on `N ≥ N₀` vertices has a `5`-set `W` with
> `bip(G) − bip(G−W) ≤ (2N−5)/5`,

which together with the known base cases (`N ≤ 200`, arXiv:2606.28041, and `N ≤ 13` re-verified here)
would give the conjecture. **(★) is not a result of mine** — it is at least as strong as the conjecture
(rule (a)); it is recorded because Theorem J shows `k = 5` is the unique scale not already refuted, and
because §7 shows exactly which proof technique cannot establish it.

## 7. R9 — the universal factor `5/2`: why every "half the incident edges" step fails

> **Lemma K.** For every graph `G` and every `W ⊆ V(G)`:
> `bip(G) − bip(G−W) ≤ ½ ( Σ_{w∈W} d(w) − e(W) )`, where `e(W) = |E(G[W])|`.

*Proof.* Fix an optimal bipartition of `G−W` and assign each vertex of `W` independently and uniformly
to a side. The expected number of new monochromatic edges is `½(e(W) + e(W, V∖W)) = ½(Σ_{w}d(w) − e(W))`,
so some assignment achieves at most that. ∎

Lemma D (`k=1`), Lemma G (`W = N[v]`, using independence to save `d(v)/2`) and the greedy bound for any
`W` are all instances or refinements of Lemma K. Now evaluate it on the sharp family:

> **Theorem L.** Let `G = C5[n]` and let `W` consist of `s` vertices from each blob (`k = 5s`, the
> *only* deletion size that is not already refuted by Theorem J). Then
> ```
> true cost      = 2ns − s²          (Theorem J)
> budget         = k(2N−k)/25 = 2ns − s²
> Lemma K bound  = ½(10ns − 5s²) = 5ns − 5s²/2
> ratio          = (5ns − 5s²/2)/(2ns − s²) = 5/2   for every n and every s.
> ```
> So on `C5[n]` the Lemma K estimate is **exactly `5/2` times both the true cost and the budget**, for
> every `s`. Consequently **no induction step at a deletion size `k ≡ 0 (mod 5)` can be closed by
> Lemma K** — and by Theorem J every other `k` is outright false on `C5[n]`. Together: *the entire
> family of "delete a set, re-insert it at half its incident edges" arguments fails, at every `k`, by
> the single factor `5/2`.*

(The two failures are of different kinds and it is worth keeping them apart: for `k ≢ 0 (mod 5)` the
step is **false** on `C5[n]` — no technique can repair it; for `k = 5s` the step is **true with
equality** on `C5[n]`, but Lemma K's estimate — which is tight at `k = 1`, where `½·2n = n` is exactly
the cost — overshoots by `5/2` as soon as `W` meets several blobs, because it ignores that the optimal
placement of `W` is aligned with the blob pattern.)

*Proof.* `Σ_{w∈W} d(w) = 5s·2n = 10ns`; `e(W) = 5s²` (`s²` edges between each of the `5` consecutive
pairs of blobs). Insert into Lemma K and divide. ∎

This is, in my view, the single most useful thing established here: it isolates the **exact** deficiency
of the whole F4 family in one number. Any proof of (★) must exploit the *correlation* between the
optimal bipartition of `G−W` and the structure of `W` (on `C5[n]` the optimal placement of `W` is
"aligned with the blob pattern", giving `2ns − s²` instead of the random `5ns − 5s²/2`); no argument
that treats the re-insertion as unstructured can succeed.

## 8. R10 — an exact counterexample hunt among blow-ups

By Lemma A the conjecture restricted to blow-ups of a fixed `H` reads
`25 · min_S (uncut a-weight) ≤ (Σ_u a_u)²` for all integer `a ≥ 0`. Two exact reductions:
* the left side is **monotone under adding edges** to `H` (every `q_S` gains a non-negative term), so it
  suffices to search **maximal** triangle-free `H`;
* it is **invariant under merging twins** (a blow-up of a blow-up is a blow-up), so it suffices to search
  **twin-free** `H`.

(A maximal triangle-free graph is automatically connected for `n ≥ 2`, and contracting twins keeps it
maximal and triangle-free, so RMTF graphs on `≤ n` vertices really do dominate everything on `≤ n`
vertices.) The RMTF graphs are extremely sparse: `1, 1, 1, 2, 4, 8, 24, 91, 441` for
`n = 5, 8, 9, 10, 11, 12, 13, 14, 15` (files `f8_rmtf_*.g6`, produced by the F8 lane in this directory
by filtering `geng -t -c`; my scripts re-assert triangle-freeness of every graph they read, and the
`n = 5` entry is `C5`, as it must be). `f4_hunt.py` runs a
steepest-ascent integer hill-climb (unit moves `a_i → a_i − 1, a_j → a_j + 1`, plateau walks, exact
`int64`; seeds = every `5`-cycle of `H` at weight `5` plus random restarts at totals `T = 25, 50, 75`)
maximising `min_S (uncut weight)` for each `H` with `n ≤ 13` — 41 graphs, covering by the two reductions
**all** blow-ups of **all** triangle-free graphs on `≤ 13` vertices, at every blow-up size.

Result (`f4_hunt13.log`): the maximum of `25·bip(H[a])/(Σa)²` found is exactly `1`, attained on every
`H` by putting weight `5` on the five vertices of a `5`-cycle and `0` elsewhere — i.e. by `C5[t]` — and
**never exceeded**. No counterexample. (This is a search, not a proof: the hill-climb is not exhaustive.
It does, however, reproduce the known optimum on every one of the 41 graphs.)

## 9. Where I got stuck — the exact missing statement

Everything above reduces the F4 programme to **(★)**: *every triangle-free `G` on `N ≥ N₀` vertices
contains `5` vertices `W` with `bip(G) − bip(G−W) ≤ (2N−5)/5`.*

What is known here, exactly:
* (★) is **sharp**: `C5[n]` attains equality for every `n` (Theorem J), as does every `k = 5s` version.
* (★) is **not provable by Lemma K** (any random/greedy re-insertion bound), which overshoots by the
  factor `5/2` on `C5[n]` (Theorem L). Lemma K does give (★) for any `5`-set `W` with
  `Σ_{w∈W} d(w) − e(W) ≤ (4N−10)/5`, e.g. five vertices of degree `≤ (4N−10)/25 ≈ 0.16N`; and the
  `k = 1` step of Lemma D already suffices when a single vertex of degree `≤ 2⌊(2N−1)/25⌋+1` exists.
* The high-degree end is settled: `δ(G) > 3N/8` ⟹ conjecture (Theorem C, via Häggkvist + Lemma A).

Putting the two ends together gives the honest positive output of family F4:

> **Corollary M (PROVED).** Let `G` be triangle-free on `N` vertices and suppose that **every** induced
> subgraph `H ⊆ G` with `M = |V(H)| ≥ 14` satisfies
> ```
> δ(H) ≤ 2⌊(2M−1)/25⌋ + 1        (≈ 0.16 M)      or        δ(H) > ⌊3M/8⌋ .
> ```
> Then `bip(G) ≤ ⌊N²/25⌋`.
>
> *Proof.* Induction on `M`. Base `M ≤ 13`: the exhaustive census gives `a_M ≤ ⌊M²/25⌋`
> (`a₅..a₁₃ = 1,1,1,2,2,4,4,5,6` versus `⌊M²/25⌋ = 1,1,1,2,3,4,4,5,6`; `M ≤ 4` forces bipartite).
> Step: if `δ(H) > ⌊3M/8⌋`, Theorem C finishes immediately. Otherwise let `v` have minimum degree; by
> Lemma D and the hypothesis `bip(H) ≤ bip(H−v) + ⌊δ(H)/2⌋ ≤ ⌊(M−1)²/25⌋ + ⌊(2M−1)/25⌋ ≤ ⌊M²/25⌋`. ∎

* **The open window is therefore exactly `4N/25 < δ(G) ≤ 3N/8`** (`0.16N < δ ≤ 0.375N`), and inside it
  the missing ingredient is a *structured* re-insertion: a `5`-set `W` and an optimal bipartition of
  `G−W` whose interaction is at least `2.5` times better than random. I could not produce one, and I
  have no example showing it is impossible — on `C5[n]` such a `W` exists (any blob transversal).

Secondary open point: Theorem C uses `δ > 3N/8`; the natural next step is to push the C5-homomorphism
hypothesis down using Jin's `10N/29` theorem, but that only yields `3`-colourability, not a `C5`-colouring,
and Lemma A needs a `C5`-colouring. A `C5`-blow-up structure theorem valid for `δ > cN` with
`c < 3/8` would immediately shrink the open window by Theorem B.
