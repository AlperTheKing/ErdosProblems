# Erdős #23 — Family F1: EFFECTIVE THRESHOLD

**Round 1 report.**  Everything below is either a complete proof, an exact
integer computation (with the script that produced it), or an explicitly
labelled search.  Nothing is asserted that I have not proved or computed.

Notation throughout: `G` is a finite simple triangle-free graph, `N = |V(G)|`,
`e(G) = |E(G)|`, `maxcut(G)` the maximum number of edges crossing a bipartition,
`bip(G) = e(G) - maxcut(G)`, and

```
a(N) = max { bip(G) : G triangle-free, |V(G)| = N }.
```

Conjecture (E): `a(N) <= N^2/25` for every `N`.  Since `a(N)` is an integer this
is equivalent to `a(N) <= floor(N^2/25)`.

Published input used (and only this): **`a(5m) = m^2` for `1 <= m <= 40`**
(arXiv:2606.28041), i.e. exact values at multiples of five up to `N = 200`.

## 1. Two elementary lemmas

### Lemma 1 (edge monotonicity)
*If `G ⊆ G'` on the same vertex set then `bip(G) ≤ bip(G')`.*

**Proof.** It suffices to add one edge `f = uv`. Every bipartition of `G+f` cuts
at most one more edge than the same bipartition of `G`, so
`maxcut(G+f) ≤ maxcut(G) + 1`. Hence
`bip(G+f) = e(G)+1 − maxcut(G+f) ≥ e(G)+1 − maxcut(G) − 1 = bip(G)`. ∎

**Corollary 1.1.** `a(N)` is attained by a *maximal* triangle-free graph, i.e.
one in which every two non-adjacent vertices have a common neighbour.  (Add
edges while triangle-freeness survives; `bip` never drops, `N` never changes.)
This is what makes the exhaustive computations of §5 feasible: there are only
`3, 4, 6, 10, 16, 31, 61, 147, 392, 1274, 5036` maximal triangle-free graphs on
`5,…,15` vertices (OEIS A006855), against `10^10` triangle-free ones on 15.

### Lemma 2 (exact weighted blow-up identity)
Let `H` be a graph on `V(H) = {1,…,h}` and let `t = (t_1,…,t_h)` be positive
integers.  Write `H[t]` for the blow-up (part `V_i` of size `t_i`, independent;
complete bipartite between `V_i` and `V_j` iff `ij ∈ E(H)`).  Then

```
   e(H[t]) = Σ_{ij ∈ E(H)} t_i t_j ,
   maxcut(H[t]) = max_{S ⊆ V(H)}  Σ_{ij ∈ E(H), |S∩{i,j}| = 1} t_i t_j ,
   bip(H[t])    = min_{S ⊆ V(H)}  Σ_{ij ∈ E(H), |S∩{i,j}| ≠ 1} t_i t_j .
```

**Proof.** The formulas for `e` and the "≥/≤" from `S`-induced bipartitions are
immediate.  For the converse, let `(A,B)` be *any* bipartition of `V(H[t])` and
put `x_i = |A ∩ V_i| / t_i ∈ [0,1]`.  Between `V_i` and `V_j` (with `ij ∈ E(H)`)
*all* `t_i t_j` pairs are edges, so the number of cut ones is exactly
`|A∩V_i||B∩V_j| + |B∩V_i||A∩V_j| = t_i t_j (x_i + x_j − 2x_i x_j)`.  Hence

```
   cut(A,B) = F(x),   F(x) = Σ_{ij ∈ E(H)} t_i t_j (x_i + x_j − 2 x_i x_j).
```

`F` is *multilinear* (affine in each variable separately), so its maximum over
the box `[0,1]^h` is attained at a vertex of the box: fix all coordinates but
one; `F` is affine in it; move it to `0` or `1` without decreasing `F`; iterate.
A vertex of the box is the indicator of a set `S ⊆ V(H)`, and then
`F(1_S) = Σ_{ij ∈ E(H) crossing S} t_i t_j`.  Therefore
`maxcut(H[t]) = max_S (…)`, and subtracting from `e(H[t])` gives the third
identity. ∎

*Verification:* `f1_check_lemmaA.py` compares the identity against brute-force
`bip` of the explicitly expanded blow-up for every triangle-free graph on `≤ 5`
vertices and random weight vectors — 2577 tests, 0 mismatches; and the scaling
form `bip(H[t,…,t]) = t² bip(H)` — 0 mismatches.

### Corollary 2.1 (balanced scaling)
`bip(H[t,…,t]) = t² · bip(H)`, and `H[t]` is triangle-free iff `H` is.  Hence

```
   a(tN) ≥ t² a(N)     for all t, N ≥ 1.                             (B)
```

**Also invariant under balanced blow-up:** `e/N²`, `δ/N`, `Δ/N`, `α/N`,
`bip/N²`, the homomorphism type, and membership in any homomorphism-closed
class.  This is the engine of everything below.

## 2. There is no asymptotic slack (the F1 collapse)

### Theorem 3
`c := lim_{N→∞} a(N)/N²` exists and equals `sup_{N ≥ 1} a(N)/N²`.

**Proof.**  `a` is nondecreasing (add an isolated vertex), and `a(N) ≤ e ≤ N²/4`,
so `β := sup_N a(N)/N² ≤ 1/4` is finite.  Fix `N`.  For `M ≥ N` set
`t = ⌊M/N⌋ ≥ 1`; then `M ≤ (t+1)N` and, by monotonicity and (B),
`a(M) ≥ a(tN) ≥ t² a(N)`, so

```
   a(M)/M² ≥ t² a(N) / ((t+1)² N²)  →  a(N)/N²      (M → ∞).
```

Hence `liminf_M a(M)/M² ≥ a(N)/N²` for every `N`, so
`liminf ≥ β ≥ limsup`.  The limit exists and equals `β`. ∎

### Theorem 4 (the collapse) — OBSTRUCTION
For **every** `N0 ≥ 1`:

```
   [ a(N) ≤ N²/25 for all N ≥ N0 ]   ⟺   [ a(N) ≤ N²/25 for all N ≥ 1 ].
```

**Proof.** (⇐) trivial. (⇒) Let `M < N0` and pick `t` with `tM ≥ N0`.  By (B),
`a(M) ≤ a(tM)/t² ≤ (tM)²/(25 t²) = M²/25`. ∎

**What this kills.**  Family F1 was set up on the hypothesis that, because
`N ≤ 200` is settled, an effective statement "for `N ≥ N0` with `N0 ≤ 200`"
would finish the conjecture.  It would — but so would "for `N ≥ 10^{10^{100}}`",
and neither is any easier than the full conjecture.  **There is no threshold to
exploit.**  The correct reading of F1(iii) is therefore: *the sharpest statement
of the form "`bip(G) ≤ N²/25` for `N ≥ N0`" that anyone can ever prove without
proving the conjecture outright is the empty one.*  Any `N0` is as hard as
`N0 = 1`.

### Theorem 5 (asymptotic bounds are automatically effective)
(a) If `limsup_N a(N)/N² ≤ γ` then `a(N) ≤ γ N²` **for every `N ≥ 1`**.

(b) More generally let `C` be any class of triangle-free graphs closed under
balanced blow-up (e.g. an edge-density window, a min-degree-ratio window, a
homomorphism-closed class, "contains no blow-up of `F`").  If
`bip(G) ≤ γ|V(G)|² + o(|V(G)|²)` for `G ∈ C`, then `bip(G) ≤ γ|V(G)|²` for every
`G ∈ C`, with no exceptional small cases.

**Proof.** (a) is Theorem 3.  (b): if some `G ∈ C` on `N` vertices had
`bip(G) > γN²`, then `G[t] ∈ C` for all `t` (blow-up closure), `|V(G[t])| = tN`
and `bip(G[t]) = t² bip(G) > γ(tN)²` by Corollary 2.1, contradicting the
asymptotic bound along `t → ∞`. ∎

### Corollary 5.1 (answer to F1(ii))
Balogh–Clemen–Lidický (Combinatorica 43 (2023) 1059–1079, arXiv:2103.14179)
prove, by flag algebras, that every triangle-free graph can be made bipartite by
deleting at most `n²/23.5` edges, and that the conjecture holds for edge density
`≤ 0.2486` and for edge density `≥ 0.3197` (density `= e/binom(n,2)`).  All three
statements are asymptotic in nature; by Theorem 5 each of them holds **for every
`n ≥ 1`, `N0 = 1`, with no lost constant**.

So the honest answer to "are the general bounds effective, and what is `N0`?" is:
*they are automatically effective and `N0 = 1`; effectivity was never the
obstruction*.  What has to improve is the constant `1/23.5 = 0.042553…` down to
`1/25 = 0.04`, and only inside the density window `(0.2486, 0.3197)` — outside
it the conjecture is already a theorem at every `n`.

### Corollary 5.2 (constraint on any counterexample, at every N)
If `G` is triangle-free with `bip(G) > |V(G)|²/25` then
`0.2486 < e(G)/binom(N,2) < 0.3197`, i.e. `0.1243 N² ≲ e(G) ≲ 0.1599 N²`.
(For orientation: the extremal `C5[n]` has density exactly `2/5 = 0.4`, well
inside BCL's *proved* region — the conjecturally extremal object is *not* in the
open window.)

### Theorem 6 (finite computation can only disprove) — OBSTRUCTION
Because `c = sup_N a(N)/N²` (Theorem 3), knowing `a(N)` exactly for all `N ≤ M`
gives **no** information about `a(N)` for `N > M`: the values `a(N)`, `N ≤ M`,
only bound finitely many terms of a supremum.  Consequently the entire programme
"compute `a(N)` exactly for larger and larger `N`" — of which the published
`a(5m) = m²`, `m ≤ 40` is an instance — is structurally incapable of proving
(E).  It can only ever *refute* (E), or (via Theorem 7) settle finitely many
extra values below its own range.

## 3. What the published data really gives (answer to F1(i))

### Theorem 7 (all `N ≤ 40`, including non-multiples of five) — PROVED
`a(N) ≤ N²/25` for every `N ≤ 40`.

**Proof.**  Let `N ≤ 40`.  Then `5N ≤ 200`, so the published result gives
`a(5N) = N²`.  By (B) with `t = 5`, `25 a(N) ≤ a(5N) = N²`. ∎

This settles the 32 values `N ≤ 40` with `5 ∤ N`, which the published theorem
does *not* cover (the naive `a(N) ≤ a(5⌈N/5⌉) = ⌈N/5⌉²` is strictly weaker than
`N²/25` at every non-multiple).  It is a one-line consequence of Lemma 2, but it
is the only part of the "non-multiples" question that is currently answerable.

### Theorem 8 (and the exact frontier at `41 ≤ N ≤ 200`)
Let `K` be the published data `a(5m)=m² (m ≤ 40)`, `M` the monotonicity of `a`,
`B` the blow-up inequality (B).  The best upper bound on `a(N)` derivable from
`K + M + B` is

```
   U(N) = min { ⌈tN/5⌉² / t²  :  t ≥ 1, tN ≤ 200 }.
```

**Proof.**  Any chain of applications of `M` and `B` starting from `K` has the
form `a(N) ≤ a(N')/t²` with `N' ≥ tN` and `a(N')` bounded by `K+M`, i.e.
`a(N') ≤ ⌈N'/5⌉²` (needs `N' ≤ 200`); the bound is minimised at `N' = tN`, and
`⌈tN/5⌉²/t²` composed over `t = t₁t₂` is again of the same shape, so the family
is closed. ∎

`U(N) ≤ N²/25` iff `5 | tN` for some admissible `t`, i.e. (for `5∤N`) iff
`N ≤ 40`.  Computation (`f1_bounds.py`, `f1_deficits.txt`):

* `⌊U(N)⌋ ≤ ⌊N²/25⌋` exactly for `N ≤ 40` and for the multiples of 5 up to 200
  (72 values);
* for all **128** values `41 ≤ N ≤ 200` with `5∤N`, `⌊U(N)⌋ > ⌊N²/25⌋`.
  Minimum deficit `1`, attained at `N = 41, 46, 48, 53`; maximum deficit `64`
  at `N = 196`.  E.g. `N = 41`: `U = 1089/16 = 68.0625`, so `a(41) ≤ 68`, while
  (E) asks for `a(41) ≤ 67`.

**Precise missing statement.**  For a given `N` with `5∤N`, `a(N) ≤ N²/25`
follows from the single exact value

```
   a(5N) = N²          (note 5N ≤ 995 for N ≤ 199),
```

and, inside the closure `K+M+B`, from nothing weaker (a transfer
`a(N) ≤ a(tN)/t²` reaches `N²/25` only when `5 | tN`, i.e. `5 | t`, i.e.
`t ≥ 5`).  So: **settling all `N ≤ 200` costs exactly extending the published
exact-value computation from `5m ≤ 200` to `5m ≤ 995`** — and by Theorem 6 this
would still not advance the conjecture itself.

### Theorem 11 (`C5`-colourable graphs — the sharp case, at every `N`) — PROVED
Define `φ(N) = max{ bip(G) : G triangle-free, G → C5, |V(G)| = N }`.  Then

```
   φ(N) = max { min_i t_i t_{i+1}  :  t ∈ Z_{≥0}^5, Σ t_i = N }
        = n²      if N = 5n, 5n+1, 5n+2,
        = n² + n  if N = 5n+3, 5n+4,
```

and `φ(N) ≤ N²/25` for every `N`.  Hence **(E) holds, at every `N`, for every
triangle-free graph homomorphic to `C5`.**

**Proof.**  If `G → C5` via `ϕ`, put `t_i = |ϕ^{-1}(i)|`; then `G` is a spanning
subgraph of `C5[t]`, so `bip(G) ≤ bip(C5[t])` by Lemma 1.  By Lemma 2,
`bip(C5[t]) = min_S Σ_{uncut} t_i t_{i+1}`.  A 2-colouring of the odd cycle `C5`
has `1`, `3` or `5` monochromatic edges, and a sum of `≥ 1` of the five products
`t_i t_{i+1}` is at least their minimum, with the minimum realised by the
colouring whose unique monochromatic edge is the minimising one.  So
`bip(C5[t]) = min_i t_i t_{i+1} =: P`.  Finally

```
   P^5 ≤ Π_{i∈Z5} (t_i t_{i+1}) = (Π_i t_i)²  ≤  ((Σ t_i)/5)^{10} = (N/5)^{10},
```

(each `t_i` occurs in exactly two of the five products; then AM–GM), so
`P ≤ (N/5)² = N²/25`.  The closed form for the integer maximum is checked by
exhaustive search in `f1_c5_gap.py` for `N ≤ 29` and follows in general from the
same product inequality. ∎

**Corollary 11.1.**  Häggkvist proved that every triangle-free `G` with
`δ(G) > 3N/8` is homomorphic to `C5`.  Hence `δ(G) > 3N/8 ⇒ bip(G) ≤ N²/25`,
at every `N`.  (This regime is also covered by BCL's density result via
Corollary 5.1, since `δ > 3N/8` forces density `> 0.375`.)

## 5. Structure of a minimal counterexample (explicit constants)

### Lemma 13 (deletion)
For every graph `G` and vertex `v`: `bip(G) ≤ bip(G−v) + ⌊d(v)/2⌋`.

**Proof.** Take a bipartition of `G−v` with `bip(G−v)` uncut edges and insert
`v` on the side containing fewer of its neighbours; at most `⌊d(v)/2⌋` edges at
`v` are then uncut. ∎

### Theorem 14 (minimal counterexample)
Let `N` be minimal with `a(N) > N²/25` and let `G` be triangle-free on `N`
vertices with `bip(G) > N²/25`.  Then

```
   (i)   δ(G)  >  (4N − 2)/25            [Lemma 13 + minimality]
   (ii)  δ(G)  ≤  3N/8                   [Häggkvist + Theorem 11]
   (iii) 0.2486 < e(G)/binom(N,2) < 0.3197        [BCL + Corollary 5.1]
   (iv)  G may be assumed maximal triangle-free   [Lemma 1], so diam(G) ≤ 2
   (v)   α(G) ≥ δ(G) > (4N−2)/25          [N(v) is independent]
```

**Proof of (i).** `bip(G) ≥ ⌊N²/25⌋+1` and, for every `v`,
`bip(G) ≤ a(N−1) + ⌊d(v)/2⌋ ≤ ⌊(N−1)²/25⌋ + ⌊d(v)/2⌋` by minimality.  Hence
`⌊d(v)/2⌋ ≥ ⌊N²/25⌋ + 1 − ⌊(N−1)²/25⌋ > N²/25 − (N−1)²/25 = (2N−1)/25`,
so `d(v) > (4N−2)/25`. ∎

Numerically the open min-degree window is `0.16 N < δ ≤ 0.375 N`.  If one is
willing to use Jin's theorem (`δ > 10N/29 ⇒ χ ≤ 3`) together with
Chen–Jin–Koh (`δ > N/3` and `χ ≤ 3 ⇒ G` is homomorphic to an Andrásfai graph
`And(d)`), then a counterexample with `δ > 10N/29 ≈ 0.3448N` would force
`β(And(d)) > 1/25` for some `d`; §6 finds no such `d ≤ 6`.

## 6. Counterexample search over bounded-type graphs (no counterexample found)

Every triangle-free `G` equals `H[t]` where `H` is its twin quotient (in a
triangle-free graph twins are automatically non-adjacent), and `H` is
triangle-free.  Define `β(H) = sup_t bip(H[t])/(Σ t_i)²`; by Lemma 2 this is a
finite max–min of quadratic forms over the simplex, and by Theorem 3
`c = sup_H β(H)`.  By Lemma 1 the supremum over `h`-vertex `H` is attained on a
maximal triangle-free `H`.

`f1_beta_scan.py` maximises `min_S q_S(t)` by projected subgradient ascent (6
restarts × 700 iterations) over the simplex for **every** maximal triangle-free
`H` with `h ≤ 13` (`3+4+6+10+16+31+61+147+392 = 670` graphs) and verifies the
champion of each `h` in exact integer arithmetic:

```
 h :  5      6      7      8      9      10     11     12     13
 β : .040000 .039917 .039991 .039990 .039994 .040000 .039996 .039995 .039997
```

`f1_andrasfai.py` does the same for the Andrásfai graphs `And(2..6)`
(`n = 5, 8, 11, 14, 17`): `β ≈ 0.03996` in each case (the optimum concentrates
on an induced `C5`).

**Result:** no `H` with `≤ 13` vertices and no `And(d)`, `d ≤ 6`, has
`β(H) > 1/25`; every exact integer champion satisfies `25·bip(H[t]) − (Σt)² = 0`
exactly (equality is realised by `C5` sub-blow-ups).  This is a *search*, not a
proof: the subgradient method could in principle miss a global optimum.
Note also that any blow-up counterexample with `Σ t_i ≤ 40` is already excluded
by the published data (scale `t` by 5 and apply `a(5Σt) = (Σt)²`), so only
fine-grained weight vectors could hide one.

## 7. An exact obstruction to local-optimality certificates

Any scheme (flag-algebraic or otherwise) that certifies `bip ≤ γN²` using only
"the graph is triangle-free" plus "no single vertex flip improves the cut"
cannot prove anything below `γ = 1/8`:

**Witness.** `G = K_{m,m}` with parts `X, Y`; let `A` consist of half of `X` and
half of `Y`, `B` the rest.  `G` is triangle-free, `N = 2m`.  Every vertex has
`m/2` neighbours on each side, so *no single flip changes the cut at all*: the
cut is 1-locally optimal.  Its uncut count is `(m/2)² + (m/2)² = m²/2 = N²/8`,
exactly `25/8 = 3.125` times the conjectured bound.

(The example dies at order 2: moving one vertex of `X` from `B` to `A` and one
vertex of `Y` from `A` to `B` gains `2`.  I did **not** determine whether the
analogous quantity for `k`-flip local optimality stays above `1/25` for every
fixed `k`; that is the precise question one would have to answer to prove that
fixed-order flag algebras cannot reach `1/25`.  See §9.)

## 9. Where I got stuck — the exact missing statements

1. **`41 ≤ N ≤ 200`, `5 ∤ N`.**  I could not settle a single one of these 128
   values.  The exact missing statement is, for each such `N`:
   `a(5N) = N²` (equivalently `a(5N) ≤ N²`), a value outside the published
   range `5m ≤ 200`.  No argument in the closure of {published values,
   monotonicity, balanced blow-up} reaches `N²/25` there (Theorem 8), and by
   Theorem 10 the "slack at non-multiples" that one would hope to exploit does
   not exist.

2. **The `k`-flip obstruction.**  Missing statement:
   *for every fixed `k` there are triangle-free graphs `G` and cuts with no
   improving flip of `≤ k` vertices whose uncut count exceeds `|V(G)|²/25`.*
   I proved this for `k = 1` (with witness `K_{m,m}`) and disproved my own `k=2`
   candidates (`K_{m,m}` diagonal, `C5[n]` with all halves).  A proof for all
   `k` would be a precise obstruction showing fixed-order flag algebras cannot
   reach `1/25`; a *disproof* at some small `k` would identify exactly which
   local constraints a successful SDP must carry.

3. **`β(H) ≤ 1/25` for all triangle-free `H`.**  This is the conjecture itself
   in blow-up form (Theorem 3) — I state it only to record that the search of §6
   verified it numerically for all `h ≤ 13` and that the maximum is `= 1/25`,
   attained exactly on `C5` sub-blow-ups, in every one of the 670 cases.

4. **The min-degree window `0.16N < δ ≤ 0.3448N`.**  Above `10N/29` the
   Jin / Chen–Jin–Koh structure theory reduces the problem to
   `β(And(d)) ≤ 1/25` for all `d` — which I verified only for `d ≤ 6` and could
   not prove in general.  Missing statement:
   *`min_{S ⊆ Z_{3d−1}} Σ_{ij ∈ E(And(d)), ij uncut by S} t_i t_j ≤ (Σ t)²/25`
   for every `d ≥ 2` and every non-negative weight vector `t`.*
   This is a clean, self-contained, finitely-parametrised statement and looks to
   me like the most promising genuinely-new target coming out of this round.
