# Result: coordinated-trade submodularity is false

## Exact definitions

Fix a row tuple `omega` and, for each coordinate in a finite set `K`, one
alternative row.  For `S subset K`, let `omega[S]` replace exactly the
coordinates in `S`, and set

`F(S) = scopedObligationScore(G,c,omega[S])`.

The tested score is the repository's exact active-scoped score: twice the
ordered-pair collision excess in active components plus residual active
HitNeed.  Equivalently in the test implementation it is the integer pair
returned by `active_scoped_obligation_parts`, summed without floating point.

The standard lattice inequality needed for submodular uncrossing is

`F(A) + F(B) >= F(A intersection B) + F(A union B)`.

## Exact falsifier

`lattice_witness.json` is a graph-derived falsifier with `n=10`, graph6 string
“I?`cjVo{?”, three bad edges, and a complete shortest-row family generated by
the repository census code.  Starting at the listed base tuple, use coordinate
1 alternative `[5,2,8,3,6]` and coordinate 2 alternative `[6,3,9,1,7]`.

The exact `(total, collision, HitNeed)` scores are

* `F(empty) = (0,0,0)`;
* `F({1}) = (0,0,0)`;
* `F({2}) = (0,0,0)`;
* `F({1,2}) = (10,8,2)`.

Thus the submodular inequality reads `0 + 0 >= 0 + 10`, which is false.
Since the score is a cardinality, it is nonnegative; hence the base tuple and
both one-coordinate tuples are global minima.  The failure therefore persists
even when the lattice square is rooted at a global minimum.  Persistent-
component monotonicity of `activeDegree` and HitNeed cannot repair this
inequality: the simultaneous corner creates the interaction absent at both
one-coordinate corners.

The search exhausts all tested trade squares at orders 5 through 9 before the
first order-10 witness; it examined 15,008 exact alternative pairs before
returning this witness.  This establishes order-minimality within that census
search, not vertex-labelled uniqueness.

## Consequence and remaining gap

There is no submodular-uncrossing theorem for `scopedObligationScore` on the
natural coordinated-trade Boolean lattice.  Therefore a proof that a global
minimum satisfies scoped Hall cannot proceed by this lattice inequality.
The still-open theorem must exploit a restricted family of coordinated trades
with an additional compatibility invariant, or use the negative total
variation/transport argument directly.  No such compatibility theorem is
proved here.
