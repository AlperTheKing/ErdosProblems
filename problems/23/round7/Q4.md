## 0. The scheme (notation)

H triangle-free on n vertices, L(x) = sum_v x_v.  For a cut S,
q_S(x) = sum over edges uv monochromatic w.r.t. S of x_u x_v, psi(H,x) = min_S q_S(x).
Blow-up identity: bip(H[a]) = min_S sum_{uv mono} a_u a_v = N^2 psi(H, a/N).

Scheme at multiplier degree 2d (with nu_S = c*lambda_S substituted, so everything is LINEAR):
  (P1) nu_S >= 0 on the orthant;   (P2) sum_S nu_S = c L^{2d};
  (P3) T := L^{2d+2} - sum_S nu_S q_S >= 0 on the orthant.
Then mu_S(x) = nu_S(x)/(c L^{2d}) is a probability distribution over cuts with
sum_S mu_S q_S <= L^2/c, hence psi(H,x) <= L(x)^2/c and max_x psi <= 1/c.  Maximising c is an SDP
whose value c* is *the value of the scheme*; c* <= 25 whenever H has an induced C5.

Certificates: (P3) after the substitution x_i = y_i^2, i.e. T(y^2) is SOS in y.  T(y^2) has only
even exponents, so its Gram splits into blocks indexed by the parity class of the exponent vector
(n = 8, degree 4: one 36x36, 28 of 8x8, 70 of 1x1 — the same shape as the earlier round).
(P1) in mode 'coef': nu_S has nonnegative coefficients.  Mode 'sosy' (nu_S(y^2) SOS, strictly more
general) is implemented in `Q4_sos.py` and was not needed.

### 1.3 THEOREM Q4-1 (collapse of globally-nonnegative multipliers)

Let lambda_S be forms of degree 2d with (i) lambda_S >= 0 on ALL of R^n (in particular SOS, or PSD
quadratic forms when d = 1) and (ii) sum_S lambda_S = L^{2d}.  Then lambda_S = c_S L^{2d} with
constants c_S >= 0 summing to 1.

Proof.  On the hyperplane P = {L = 0} the right side of (ii) vanishes while every summand on the
left is >= 0, so each lambda_S vanishes identically on P; L is irreducible, so lambda_S = L g_S.
If g_S(x0) != 0 for some x0 in P, then L changes sign transversally at x0, so lambda_S = L g_S is
negative somewhere near x0, contradicting (i).  Hence L | g_S and lambda_S = L^2 h_S with h_S >= 0
off P, hence everywhere by continuity, and sum_S h_S = L^{2d-2}.  Induct down to degree 2:
lambda_S = L^{2d-2} sigma_S with sigma_S a PSD quadratic form and sum_S sigma_S = L^2 = j j^T,
which has rank 1.  For v perpendicular to j, 0 = v^T j j^T v = sum_S v^T A_S v with all terms >= 0,
so A_S v = 0 and A_S = c_S j j^T.  QED

COROLLARY.  Under global nonnegativity the hierarchy in d is CONSTANT and equals the x-independent
averaging certificate, which is on the DEAD list (value exactly 20 on C5: for a fixed convex
combination the maximum over the simplex is at an edge concentration, Motzkin-Straus, giving 1/20).
The same divisibility argument applied to the target shows that if T is required to be globally SOS
then the degree-2d scheme is literally L^{2d-2} times the degree-2 scheme.  So task (a)'s literal
reading ("lambda_S quartic, sum = (sum x)^4, target SOS") is infeasible at every degree for every
H, including C5 — the multipliers must be read as nonnegative on the orthant only, which is what
the y-substitution supplies.

### 1.4 Domination lemma (exact; 128 cuts -> 29)

If mono(S') is contained in mono(S), setting nu_S = 0 and adding its mass to nu_{S'} preserves the
certificate: T changes by nu_S (q_S - q_{S'}), a polynomial with nonnegative coefficients, which
after x = y^2 is a sum of squares of monomials.  So the inclusion-minimal cuts suffice, exactly.
Dually every z_alpha is a diagonal entry of some parity block, so z >= 0 and dominated cuts never
attain the dual minimum either: the reduction is lossless on both sides.

### 1.5 First-order conditions at a maximiser are DEGREE-INDEPENDENT

For ANY certificate with orthant-nonnegative (not necessarily polynomial) multipliers and any
maximiser x in Z (L(x) = 1, psi(x) = 1/25): q_S(x) >= 1/25 for all S and T(x) <= 0, so T(x) = 0 and
nu_S(x) = 0 for every non-tight S; orthant-nonnegativity then forces d_j nu_S(x) = 0 for j in
supp(x).  Differentiating T at x and using sum_S d_j nu_S(x) = 50d gives, with mu_S = nu_S(x)/25 a
probability distribution supported on the TIGHT cuts,

    sum_S mu_S d_j q_S(x) = 2/25  (j in supp x),        sum_S mu_S d_j q_S(x) <= 2/25  (j outside).

The degree has cancelled, so this LP is necessary at every degree.  Computed
(`Q4_firstorder.py`): feasible at all 48 maximisers of Gamma_8 and at the C5 optimum — no
degree-independent obstruction of this type exists for these patterns.

## 3. REFUTED / CORRECTED, with the exact falsifier

**"Degree-2 multipliers are INFEASIBLE for And(3) (strict margin, 20 arc cuts)" is a statement
about the cut family, not the degree.**
Falsifier: the exact rational degree-2 certificate `Q4_cert_g8_d1.pkl`, root-gated.

adding the 17 non-arc cuts raises it to exactly 25.  The certificate puts large mass on non-arc

second-heaviest cut in the solution.  (The earlier script `round5/claude_wagner_cert3.py` defaults

degree-4 target is And(4).

## 4. Why the exact rounding is hard here, and the recipe that worked (reusable)

The optimum is TIGHT: T must vanish on the whole maximiser set Z, so every Gram is singular and
naive rounding always destroys positive semidefiniteness.  What works:

1. **Compute Z exactly.**  psi is concave along any direction whose positive and negative supports
   are independent sets, so the segment joining two C5-concentrations differing by one vertex swap
   consists entirely of maximisers.  Cross-checked by exhaustive exact integer search over blow-ups
   (`Q4_blowup.cpp`, `Q4_argmax.py`): for Gamma_8 and N = 10, 15 the maximiser supports are exactly
   the predicted ones.
2. **Two proved face conditions.**
   (F1) nu_{S,m} = 0 whenever supp(m) is inside supp(x) for some x in Z at which S is not tight
        (Gamma_8: 1044 entries -> 284; Petersen: 7425 -> 2685);
   (F2) Q_b U_b = 0 with U_b spanning {v_b(x) : x in Z} (Gamma_8: 244 of 330 Gram dimensions).
   Under (F1)+(F2) the tightness T|_Z = 0 becomes AUTOMATIC — this is what makes rounding possible
   at all.
3. **Facial reduction where needed.**  For Gamma_8 the (F2) face still has max-margin 0: the true
   minimal face has 8 more kernel dimensions in the 36x36 block (rank 12, not 20).  Those are read
   off the maximum-rank numerical solution and rationalised from its RREF (entries
   0, +-1, +-2, +-3, +-3/2, +-2/3, +-6; rationalisation error 5e-8, ||Q U^T|| = 9e-9).  This is only
   a SEARCH HEURISTIC; the final object is verified from scratch.  (Petersen needed no facial
   reduction: margin 1.28 already on the (F2) face.)
4. **Re-solve on that face maximising the margin** (Gamma_8: 0 -> 9.36), then **pin the numerically
   zero multiplier entries and re-solve with the live ones bounded below by the same margin**
   (Petersen: 0.48) so that rounding can never push a live multiplier negative.
5. **Round and repair exactly.**  Round the multipliers, repair the normalisation exactly, freeze T;
   correct the 330 (resp. 715) coefficient identities with kernel-preserving Gram probes
   P(E_ij+E_ji)P plus normalisation-preserving multiplier directions e_{S,m} - e_{S0,m}; select a
   well-conditioned column subset by rank-revealing QR; solve the residual system EXACTLY by
   modular elimination with rational reconstruction, escalating the Mersenne prime
   2^521-1 -> 2^1279-1 -> 2^2203-1 until the exact Fraction re-check passes.
6. **Verify** with `Q4_verify.py`, then with the independent gate `Q4_gate.py`.

Traps recorded, both of which produced silently wrong objects before they were found:
* a 61-bit modulus is far too small — the exact projectors carry denominators ~10^22 and rational
  reconstruction fails without warning (now the code escalates and always re-checks in Fractions);
* the multiplier correction columns enter the residual system with the OPPOSITE sign to the Gram
  columns (increasing nu_S lowers T); with the wrong sign the certificate missed by 1e-58 and the
  exact verifier caught it.

## 6. And(4): the exact dual ray  (task (c))

`Q4_dualcert_g11_d1.pkl` stores a rational moment vector z on the 1001 degree-4 exponents of
Gamma_11 whose 386 parity blocks (largest 66x66) are all PSD by exact LDL^T, with

    num = sum_alpha muT(alpha) z_alpha = 8481669033/5000000,
    den = sum_m muD(m) * min_S zhat_S(m) = 510871843/7500000 > 0,
    zhat_S(m) = sum_{(u,v) in mono(S)} z_{m+e_u+e_v},
    **c*(Gamma_11, degree 2) <= num/den = 25445007099/1021743686 = 24.903512933... < 25.**

Weak duality, proved inline (no duality theory): for any primal-feasible (c, nu, Q),
sum_alpha muT(alpha) z_alpha = sum_{S,m} nu_{S,m} zhat_S(m) + sum_b <Z_b,Q_b>
  >= sum_m (sum_S nu_{S,m}) min_S zhat_S(m) = c * den.
`Q4_dualgate.py` re-derives everything from the definitions and computes den as a minimum over ALL
2^10 cuts, so the refutation covers the scheme with the full cut family: the best bound the
degree-2 scheme can prove for And(4) is >= 1021743686/25445007099 = 0.04015504 > 0.04.

Whether degree 4 closes this gap for And(4) is OPEN and is the concrete next computation; the SDP
as formulated here did not run (section 5).

## 8. BLOCKED

* **And(4) = Gamma_11 at degree 4.**  Blocking fact (exact): the degree-2 scheme is capped at
  25445007099/1021743686 < 25 by the dual ray above, so degree 4 is genuinely required; the
  degree-4 SDP (8008 target coefficients, one 286x286 block, 9009 equalities, tens of thousands of
  multiplier variables) produced no iterate in an hour with SCS.  The lever not pulled:
  symmetry-adapted block diagonalisation under Aut(Gamma_11) (order 22) — provably lossless,
  reduces the free variables ~22-fold.  Until that is done, nothing is known about the degree-4
  value for And(4).
* **The whole Andrasfai family.**  Each And(k) needs its own certificate; the method gives no
  uniform-in-k statement, and the cut count of the inclusion-minimal family grows fast
  (5, 29, 319, 4397 for k = 2, 3, 4, 5).  Nothing here approaches the Vega graphs.
* **Exact certificates for non-tight patterns are easy; the difficulty is entirely the tightness.**
  Any pattern with an induced C5 has max_x psi = 1/25 exactly, so every certificate lies on the
  boundary of the SDP cone, the Gram is forced singular, and the exact stage needs the full
  machinery of section 4 (face conditions + facial reduction + modular repair).  There is no
  shortcut through a strictly feasible relaxation, because a bound 1/(25-eps) is not the
  conjecture.
