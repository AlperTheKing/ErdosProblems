# Q4 — higher-degree Positivstellensatz certificates for max_x psi(H,x) <= 1/25

STATUS: IN PROGRESS (stub written first, updated as results land).

Label Q4. Mechanism: push the C5 degree-2 multiplier certificate to degree-4 multipliers on
And(3) = Wagner = Gamma_8, exact-rational verification, honest scaling report.

## 0. Scheme under test (notation fixed here, used throughout)

H triangle-free on vertex set V, |V| = n. L(x) = sum_v x_v. For a cut S subset V,
q_S(x) = sum over edges uv monochromatic w.r.t. S of x_u x_v, and psi(H,x) = min_S q_S(x).
Goal: max_{x>=0} psi(H,x) <= 1/25.

Multiplier scheme at multiplier degree 2d:
  (M1) lambda_S(x) >= 0 for x >= 0, deg 2d;
  (M2) sum_S lambda_S = L^{2d};
  (M3) L^{2d+2} - c * sum_S lambda_S q_S >= 0 on x >= 0.
Then max_x psi(H,x) <= 1/c. Target c = 25.  Substituting nu_S = c*lambda_S makes (M1)-(M3)
jointly LINEAR in (c, nu, Gram), so "maximise c" is a genuine SDP with a meaningful value:
the scheme's own best bound is max_x psi <= 1/c*.

Certificates used for the two nonnegativity requirements:
  (M3) after x_i = y_i^2 : T(y^2) is SOS in y.  T(y^2) has only even exponents, so its Gram
       splits into blocks indexed by the parity class of the exponent vector.  This is exactly
       the "parity-blocked" formulation of the earlier round.
  (M1) mode 'coef': nu_S has nonnegative coefficients;  mode 'sosy': nu_S(y^2) is SOS in y
       (strictly more general; 'coef' is its diagonal restriction).

## 1. Results

### 1.1 PROVED (exact, no computation): the globally-nonnegative multiplier hierarchy is CONSTANT
### in the degree, and equals the fixed-averaging certificate that is already on the DEAD list.

THEOREM Q4-1.  Let C be any family of cuts and let lambda_S, S in C, be real forms of degree 2d
in x_1..x_n with
   (i)  lambda_S(x) >= 0 for ALL x in R^n   (in particular: lambda_S SOS, or lambda_S a PSD
        quadratic form when d = 1), and
   (ii) sum_{S in C} lambda_S = L^{2d}, L = x_1 + ... + x_n.
Then there are constants c_S >= 0 with sum_S c_S = 1 and lambda_S = c_S * L^{2d} for every S.

Proof.  Let P = {L = 0}, a real hyperplane. On P the right side of (ii) vanishes and every
summand on the left is >= 0, so each lambda_S vanishes identically on P.  L is irreducible, so
L | lambda_S; write lambda_S = L g_S.  If g_S did not vanish identically on P, pick x0 in P with
g_S(x0) != 0; L changes sign transversally at x0, so lambda_S = L g_S takes negative values in
every neighbourhood of x0, contradicting (i).  Hence g_S vanishes on P, so L | g_S and
lambda_S = L^2 h_S with deg h_S = 2d-2.  h_S >= 0 off P, hence everywhere by continuity, and
sum_S h_S = L^{2d-2}.  Induct down to degree 2: lambda_S = L^{2d-2} sigma_S with sigma_S a
quadratic form, sigma_S >= 0 on R^n (i.e. PSD, matrix A_S), and sum_S A_S = J = j j^T (rank 1).
For any v perpendicular to j, 0 = v^T J v = sum_S v^T A_S v with all terms >= 0, so v^T A_S v = 0
and, A_S being PSD, A_S v = 0.  Thus A_S = c_S j j^T and lambda_S = c_S L^{2d}.  QED

COROLLARY Q4-2.  Under (i)+(ii) the scheme degenerates to the x-independent (fixed averaging)
certificate  sum_S c_S q_S(x) <= L(x)^2 / c  for constants c_S, at EVERY degree 2d.  That
certificate is on the DEAD list: its optimum on C5 is exactly c = 20 (Motzkin-Straus: for any
distribution c_S, max over the simplex of sum_S c_S q_S is attained at an edge concentration and
is >= bip(H)/(4|E|); on C5 that is 1/20 > 1/25).  So the *global* SOS reading of task (a) is
infeasible at every degree for every H, including C5 itself.

CONSEQUENCE for the assignment.  "lambda_S quartic with sum_S lambda_S = (sum x)^4 and
(sum x)^6 - 25 sum lambda_S q_S SOS" must be read with lambda_S nonnegative ON THE ORTHANT only.
The same divisibility argument applied to the target shows more: if in addition the target
L^{2d+2} - 25 sum lambda_S q_S is required to be globally SOS, then it is L^{2d-2} times the
degree-2 target, so the whole degree-2d scheme is literally the degree-2 scheme.  Higher degree
can only buy something through orthant-only nonnegativity, which is what the runs below use.
