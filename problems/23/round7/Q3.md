## (a) The stability statement, made precise

### a.1 Objects

For a finite triangle-free `H` and `x` in the simplex `Δ(V(H)) = {x ≥ 0, Σ_v x_v = 1}`,

```
    ψ(H,x)  =  min_{S ⊆ V(H)}  Σ_{uv ∈ E(H), u,v both in S or both outside S}  x_u x_v .
```

Accepted base (1)–(2): the conjecture *is* `ψ(H,x) ≤ 1/25` for every triangle-free `H` and every `x`,
and `bip(H[a]) = (Σa)² ψ(H, a/Σa)` for integer weights `a`.

**Extremal configuration** `P = (C₅, uniform)`: `ψ = 1/25`.

**The C5-blow-up template.** For `φ : V(H) → ℤ₅` let `B_φ` be the graph on `V(H)` in which `uv` is an
edge iff `φ(u) − φ(v) ≡ ±1 (mod 5)`. The C5-blow-ups are exactly the graphs `B_φ` (empty classes
allowed, so all complete bipartite graphs and all edgeless graphs are C5-blow-ups).

**Distance.** The *weighted edit distance to the blow-up family* is

```
    d(H,x)  =  min_{φ : V → ℤ₅}   Σ_{uv ∈ E(H) \ E(B_φ)} x_u x_v  +  Σ_{uv ∈ E(B_φ) \ E(H)} x_u x_v .
```

`d(H,x) = 0` iff, after deleting the zero-mass vertices, `(H,x)` is a weighted C5-blow-up.
For the unweighted graph `G` on `N` vertices with `x ≡ 1/N` this is `d(G) = edit(G, blow-ups)/N²`.

**Imbalance.** `b_φ(H,x) = Σ_{i ∈ ℤ₅} | x(φ⁻¹(i)) − 1/5 |`, and `b(H,x) = min over the optimal φ`.

### a.2 Why *edit* distance, and why the distance can only see `supp(x)`

* **The Lipschitz fact (FACT A).** For graphs `H, H'` on the same vertex set,
  `|ψ(H,x) − ψ(H',x)| ≤ Σ_{uv ∈ E(H) Δ E(H')} x_u x_v`.
  (Each fixed cut changes its monochromatic mass by at most that sum, and a minimum of functions that
  differ pointwise by `≤ ε` differs by `≤ ε`.) So `ψ` is 1-Lipschitz in exactly this distance: no
  stability constant `c` can exceed 1, and edit distance is the *unique* natural metric for which the
  trade-off "deficit vs distance" is a statement about the same quantity `ψ` controls.
* **Cut distance** also controls `ψ` (`|ψ_H − ψ_{H'}| ≤ 2δ_□`, since the monochromatic mass of `S` is
  `e(S,S)/2 + e(S̄,S̄)/2`), so a cut-distance stability conclusion is *weaker* and would still have to
  be upgraded to edit distance before the local step (a.4) can be run. It is the natural output of a
  regularity/removal argument, not the natural input of an exactness argument.
* **Homomorphism densities** are what flag algebras natively bound, but here they cannot be used to
  express "close to a C5-blow-up" for `H`: by the PLATEAU (base 2) *every* triangle-free `H` with an
  induced `C₅` — Petersen, Grötzsch, Clebsch, every Andrásfai graph — carries an extremal measure.
  **Any stability statement about `H` alone is false.** Stability here is a statement about the pair
  `(H,x)`, equivalently about `H[supp x]` weighted; `d(H,x)` above has exactly this property, because
  zero-mass vertices contribute `0` to every term.

### a.3 The statement

The pair a flag-algebra exactness proof needs is:

> **(S1) Deficiency far from the extremal family.** There are `η > 0` and `c > 0` such that every
> triangle-free `(H,x)` with `d(H,x) ≥ η` satisfies `ψ(H,x) ≤ 1/25 − c`.
>
> **(S2) Local exactness.** There is `η > 0` such that every triangle-free `(H,x)` with
> `d(H,x) < η` satisfies `ψ(H,x) ≤ 1/25`.

`(S1) + (S2) ⟹` the conjecture. The uniform quantitative form ("perfect stability") is

> **(S1′)** `ψ(H,x) ≤ 1/25 − c · min( d(H,x), η )` for absolute constants `c, η > 0`.

`(S1′) ⟹ (S1) + (S2)`. Part (b) measures the largest `c` compatible with the data, i.e. the empirical
function `Ψ(t) = max { ψ(H,x) : H triangle-free, d(H,x) ≥ t }`; stability is the assertion
`Ψ(t) < 1/25` for `t > 0`, perfect stability the assertion `Ψ(t) ≤ 1/25 − ct` near `0`.

### a.4 Two exact facts that fix the shape of the statement

**FACT B (balance is not part of the distance, and must not be).** Inside the blow-up family
(`d = 0`) one has `ψ(C₅[m], x) = min_i m_i m_{i+1}` where `m_i` are the class masses, and

```
    max { min_i m_i m_{i+1} : m ≥ 0, Σ m_i = 1 } = 1/25 ,  attained only at m = (1/5,…,1/5).
```

Writing `m_i = 1/5 + δ_i` (`Σδ_i = 0`), `min_i m_i m_{i+1} = 1/25 + (1/5)·min_i(δ_i + δ_{i+1}) + O(‖δ‖²)`
and `min_i(δ_i+δ_{i+1}) ≤ −κ‖δ‖₁` with `κ > 0` absolute, because `I + P` is invertible on `ℤ₅`
(the odd cycle: `δ_i + δ_{i+1} = 0 ∀i ⟹ δ = 0`). So the deficit is *linear* in the imbalance, and
unbalanced blow-ups are at distance `0` with `ψ < 1/25`: the distance in (S1)/(S1′) must be to the
**whole** blow-up family, and the balance is then handled by the displayed exact optimisation, which
is where "sharp only at `C₅[n]`" comes from.

**FACT C (the extremal family is `d`-closed but not `ψ`-isolated as a set of graphs).** By PLATEAU the
set of extremal *pairs* is `{(H,x) : H triangle-free, supp(x) induces a C5-blow-up with balanced class
masses}`; the graph `H` outside `supp(x)` is arbitrary. Every stability proof must therefore be
insensitive to `H − supp(x)`; in particular no argument that inspects global invariants of `H`
(degrees, spectrum, densities) can work — which is precisely the failure mode recorded for the dead
families A6, A10, A17 of the approach registry.
