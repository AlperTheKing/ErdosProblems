# Q3 — Stability for Erdős #23 (`bip(G) ≤ N²/25`)

Round 7, label **Q3**. Mechanism: *stability, in the form every flag-algebra exactness proof needs.*
Every number below is an exact integer or exact rational. Floating point appears only as a decimal
gloss and inside search heuristics, never on an acceptance path.

**One-line summary.** Stability is *not* the missing ingredient for this problem: the near-extremal
density range is already covered unconditionally by Erdős–Győri–Simonovits + Häggkvist (BCL Thm 4),
the flag-algebra bound that would have to be stabilised is `1/23.5 ≠ 1/25` (so every
stability-from-flag-algebras theorem in the literature fails its hypothesis at step 0), and the
remaining open density band contains no near-extremal configuration at all — over my complete
corpora the maximum of `bip/N²` inside that band is `7/225 = 0.03111`, a factor `0.778` below `1/25`.
What I *can* deliver from the mechanism: an exact empirical trade-off curve (complete enumerations),
two uniqueness theorems at the sharp sizes `N = 10, 15`, and one proved unconditional linear-stability
theorem on the hom-to-`C₅` class.

## (a) The stability statement, made precise

### a.1 Objects

For a finite triangle-free `H` and `x` in the simplex `Δ(V(H)) = {x ≥ 0, Σ_v x_v = 1}`,

```
    ψ(H,x)  =  min_{S ⊆ V(H)}  Σ_{uv ∈ E(H), u,v both in S or both outside S}  x_u x_v .
```

By accepted base (1)–(2) the conjecture *is* `ψ(H,x) ≤ 1/25`, and `bip(H[a]) = (Σa)²·ψ(H, a/Σa)`.
Extremal configuration `P = (C₅, uniform)`, `ψ = 1/25`.

**Blow-up template.** For `φ : V(H) → ℤ₅` let `B_φ` have `uv ∈ E(B_φ) ⟺ φ(u) − φ(v) ≡ ±1 (mod 5)`.
The `C₅`-blow-ups are exactly the `B_φ` (empty classes allowed, so complete bipartite and edgeless
graphs are blow-ups too).

**Distance (the one I use everywhere below).** Weighted edit distance to the blow-up family

```
    d(H,x) = min_{φ:V→ℤ₅}  Σ_{uv ∈ E(H)\E(B_φ)} x_u x_v  +  Σ_{uv ∈ E(B_φ)\E(H)} x_u x_v ,
```

`d(H,x) = 0` iff after deleting zero-mass vertices `(H,x)` is a weighted `C₅`-blow-up. For an
unweighted `G` on `N` vertices, `d(G) = min_φ |E(G) Δ E(B_φ)| / N²`.

**Imbalance.** `b_φ = Σ_{i∈ℤ₅} |x(φ⁻¹(i)) − 1/5|`.

### a.2 Why edit distance, and why it can only see `supp(x)`

* **FACT A (Lipschitz, proved).** For `H, H'` on one vertex set,
  `|ψ(H,x) − ψ(H',x)| ≤ Σ_{uv ∈ E(H)ΔE(H')} x_ux_v`: each cut changes its monochromatic mass by at
  most that sum, and a min of functions differing pointwise by `≤ ε` differs by `≤ ε`. So `ψ` is
  1-Lipschitz in exactly this metric — no stability constant can exceed `1`, and this is the metric
  in which "deficit vs distance" is a statement about the quantity `ψ` actually controls.
* **Cut distance** also controls `ψ` (`|ψ_H − ψ_{H'}| ≤ 2δ_□`, since the monochromatic mass of `S` is
  `½e(S,S) + ½e(S̄,S̄)`), so a cut-metric conclusion is strictly weaker and would still have to be
  upgraded to edit distance before any local step can run. It is the natural *output* of a
  regularity argument, not the natural *input* of an exactness argument.
* **Homomorphism densities cannot express "H is close to a blow-up" here.** By PLATEAU (base 2)
  *every* triangle-free `H` containing an induced `C₅` — Petersen, Grötzsch, Clebsch, every Andrásfai
  graph — carries an extremal measure. **Any stability statement about `H` alone is false.** Stability
  is a statement about the *pair* `(H,x)`; `d(H,x)` has that property because zero-mass vertices
  contribute `0` to every term. (Verified: on the Wagner graph the exhaustive optimum at `Q = 40` is
  `bip = 64 = 1600/25` at `w = (7,8,0,8,8,0,8,1)` — two zero weights, `d = 0`.)

### a.3 The statement

> **(S1) Deficiency far from the extremal family.** `∃ η, c > 0`: every triangle-free `(H,x)` with
> `d(H,x) ≥ η` has `ψ(H,x) ≤ 1/25 − c`.
>
> **(S2) Local exactness.** `∃ η > 0`: every triangle-free `(H,x)` with `d(H,x) < η` has
> `ψ(H,x) ≤ 1/25`.

`(S1)+(S2) ⟹` the conjecture. The uniform quantitative version — *perfect stability* in the sense of
Pikhurko–Sliačan–Tyros, see (c) — is

> **(S1′)** `ψ(H,x) ≤ 1/25 − c·min(d(H,x), η)`, equivalently `d(H,x) ≤ C·(1/25 − ψ(H,x))` for
> `d ≤ η`, with `C = 1/c`.

The empirical object of part (b) is `Ψ(t) = max{ψ(H,x) : d(H,x) ≥ t}` and the empirical constant is

```
    R  =  d / (1/25 − ψ)  =  25·dist / (Q² − 25·bip)      (exact integer ratio; Q = Σ weights)
```

so **perfect stability ⟺ `sup R < ∞`** and **classical stability ⟺ `Ψ(t) < 1/25` for every `t > 0`**.

### a.4 Two exact facts that fix the shape

**FACT B (balance is not part of the distance and must not be).** Inside the family (`d = 0`),
`ψ(C₅[m],x) = min_i m_i m_{i+1}`, maximised only at `m ≡ 1/5`; writing `m_i = 1/5+δ_i`,
`min_i m_im_{i+1} = 1/25 + (1/5)min_i(δ_i+δ_{i+1}) + O(‖δ‖²)` and `min_i(δ_i+δ_{i+1}) ≤ −‖δ‖₁/25`
because `(I+P)⁻¹ = ½(I−P+P²−P³+P⁴)` on `ℤ₅` has `‖·‖_{1→1} = 5/2`. So unbalanced blow-ups sit at
distance `0` with `ψ < 1/25`: the distance in (S1)/(S1′) must be to the **whole** blow-up family, and
balance is then settled by the displayed exact optimisation — that is where "sharp only at `C₅[n]`"
comes from.

**FACT C.** By PLATEAU the extremal pairs are `{(H,x) : supp(x) induces a balanced C₅-blow-up}` with
`H − supp(x)` arbitrary. Every stability proof must be insensitive to `H − supp(x)`; no argument
reading global invariants of `H` (degrees, spectrum, neighbourhood-cut statistics) can work — exactly
the failure mode already recorded for the dead families A6, A10, A17.

## (c) What the literature's exactness machinery needs, and whether this problem qualifies

### c.1 Pikhurko–Sliačan–Tyros, *Strong forms of stability from flag algebra calculations*, JCTB 135 (2019) 129–178 (arXiv:1706.02612)

Their setting, verbatim in structure: fix `κ`, a hereditary family `𝒢 = Forb(ℱ)` and a function
`γ : 𝒢⁰_κ → ℝ`; the objective is

```
        Λ(G) := Σ_{H ∈ 𝒢⁰_κ} γ(H) P(H,G),      λ(G) := Λ(G)/C(v(G),κ),
        Λ(n,𝒢) := max{Λ(G) : G ∈ 𝒢, v(G) = n},   λ(𝒢) := lim_n λ(n,𝒢).
```

Their notions (verbatim): the problem is *robustly B-stable* (resp. *perfectly B-stable*) if there is
`C > 0` such that every `G ∈ 𝒢` of order `n ≥ C` satisfies
`δ_edit(G, B()) ≤ C·max(1/n, λ(n,𝒢) − λ(G))` (resp. `δ_edit(G,B()) ≤ C(λ(n,𝒢) − λ(G))`), where
`δ_edit` is normalised edit distance to the family `B()` of blow-ups of `B`. And:

> "if the problem is perfectly stable, then for all `n ≥ C` we have `Λ(n,𝒢) = Λ(n,B())` and every
> extremal graph is a blow-up of `B` (which one may call an exact result)."

This is exactly (S1′) with `C = 1/c`, and it is exactly the implication the conjecture needs.
Sufficient conditions: Theorem 4.1 (robust stability), Theorems 5.8, 5.13, 7.1 (perfect stability),
Lemma 6.2 (uniqueness of the optimal part ratios); the assumptions of Theorem 7.1 and Lemma 6.2 are
computer-verifiable, and all of them take as input a **flag-algebra certificate `𝒞` proving
`λ(𝒢) ≤ c` together with a blow-up family `B()` and `a ∈ 𝕊_m` with `λ(B(a)) = c`** — i.e. the
certificate value must *equal* the conjectured extremal value.

**Two hypotheses fail for Erdős #23, both fatally.**

1. **`bip` is not an objective of their form.** `Λ(G)` must be a *fixed finite linear combination of
   subgraph densities of bounded order* `κ`. `bip(G) = |E| − maxcut(G)` is a **minimum over `2^{N-1}`
   cuts**; it is not `Σ_H γ(H)P(H,G)` for any fixed `κ` (a fixed density functional is continuous in
   cut metric *and* determined by bounded-order statistics; `bip` is a min of infinitely many such
   functionals). BCL's flag-algebra treatment reflects this: each "cut construction" (rooted on
   `≤ 4` vertices, or on `C₅`) yields *one* density inequality `bip/n² ≤ Λ_j(G)`, and their bound is
   `max_G min_{j ∈ finite family} Λ_j(G)`. The extremal problem is a **max–min over a growing family**,
   which the PST framework does not cover; the whole "spectrum"/kernel machinery is defined for a
   single `Λ`.
2. **No tight certificate exists.** The best published certificate value is `1/23.5 = 0.0425532…`,
   strictly above `1/25 = 0.04`. Every PST theorem presupposes `λ(𝒢) = λ(B(a)) = ` the certificate
   value; complementary slackness at the pentagon is what the spectrum method reads off. With
   `1/23.5 > 1/25` the certificate is *not* tight at the pentagon, its SDP optimum is attained at a
   configuration that is not a `C₅`-blow-up, and there is nothing for the machinery to attach to.

**The contrast that makes this precise.** The *same extremal object* `C₅[n]` occurs in the Erdős
pentagon problem (maximise the number of `C₅`'s in a triangle-free graph), and PST Theorem 1.3 proves
that problem is **perfectly `C₅`-stable, with the unique maximiser `a = (1/5,…,1/5)`**, by their
automated method. The difference is not the extremal structure — it is that the pentagon count *is* a
bounded-order density functional and `bip` is not.

### c.2 What Balogh–Clemen–Lidický actually say (arXiv:2103.14179)

* Theorem 2: `D₂(G) ≤ n²/23.5`; `D₂(G) ≤ n²/25` when `|E| ≥ 0.3197·C(n,2)`; and when
  `|E| ≤ 0.2486·C(n,2)`.
* Verbatim, §2.1: *"Our flag algebra proof cannot deal with the density range close to 2/5, i.e.
  close to the conjectured extremal example."* — the near-extremal range is handled **not** by flag
  algebras but by Theorem 4 (min-degree removal + Häggkvist `δ > 3n/8 ⟹ hom to C₅` + the
  Erdős–Győri–Simonovits theorem "*for `K₃`-free `G` with `≥ n²/5` edges there is an unbalanced `C₅`
  blow-up `H` with `D₂(G) ≤ D₂(H)`*").
* Verbatim, §2.3: *"We believe Theorem 2 can be improved by adding more cuts to the calculation and
  possibly lead to the proof of Conjecture 1. Adding more cuts lead to marginal improvements so far."*

So the *stability step of the standard scheme is already available for this problem* — EGS Theorem 3
is a hard structure theorem that reduces the high-density range to the blow-up family exactly, which
is what stability would have provided. The bottleneck is the complementary far-from-extremal range,
where the truth (empirically `≤ 0.0311`) is far below both `1/25` and the flag bound `1/23.5`.

### c.3 Verdict on my mechanism

**Stability is not the missing ingredient.** Precisely:

* the near-extremal side is already unconditional (EGS + Häggkvist, BCL Thm 4);
* the machinery that converts "flag bound + stability" into an exact result (PST) is inapplicable at
  its first hypothesis, twice over (`bip` is not a bounded-order density functional; the available
  certificate is not tight);
* my complete enumerations show that the still-open density band contains nothing near-extremal, so a
  stability theorem there would be vacuous.

## (d) The weighted problem near the extremal object: what I could prove

### d.1 A proved unconditional linear-stability theorem on the hom-to-`C₅` class

**Theorem Q3-1.** *Let `H` be triangle-free with a homomorphism `φ` to `C₅` (equivalently `H ⊆ B_φ`),
and let `x` be any weighting. Put `MISS = Σ_{i∈ℤ₅} miss_i`, `miss_i` the `x`-mass of the pairs between
classes `i, i+1` that are **not** edges of `H`. Then*

```
        ψ(H,x)  ≤  1/25 − (18/625)·MISS  ≤  1/25 − (18/625)·d(H,x) ,        18/625 = 0.0288 .
```

*Proof.* Write `m_i = x(φ⁻¹(i))`, `p_i = m_i m_{i+1}`, `g_i = miss_i`, so `0 ≤ g_i ≤ p_i` and
`MISS = Σ g_i ≤ Σ p_i ≤ 1/4` (Motzkin–Straus for `C₅`). The five cuts
`S_i = φ⁻¹({i, i+1, i+3})` have monochromatic mass exactly `p_i − g_i` (inside `S_i` the only
template edges are the `(i,i+1)` ones, and `H ⊆ B_φ` adds none), hence `ψ ≤ min_i (p_i − g_i)`.
If some `p_i = 0` then `g_i = 0` and `ψ ≤ 0 < 1/25 − (18/625)·(1/4)`. Otherwise, with
`t_i = g_i/p_i ∈ [0,1]`,

```
   min_i(p_i − g_i) ≤ (Π_i (p_i − g_i))^{1/5} = (Π_i p_i)^{1/5}·(Π_i (1−t_i))^{1/5}
                    ≤ ((Π_i m_i)²)^{1/5} · e^{−(1/5)Σ_i t_i}
                    ≤ 5^{−2} · e^{−(4/5)·MISS} ,
```

using AM–GM `Π m_i ≤ 5^{−5}`, `1−t ≤ e^{−t}`, and
`Σ_i t_i ≥ MISS / max_i p_i ≥ 4·MISS` because `p_i ≤ ((m_i+m_{i+1})/2)² ≤ 1/4`. Finally
`y := (4/5)MISS ≤ 1/5` and `e^{−y} ≤ 1 − 0.9y` on `[0, 1/5]` (convexity: the chord from `(0,1)` to
`(0.2, e^{−0.2}) = (0.2, 0.81873…)` is `1 − 0.90634…·y ≤ 1 − 0.9y`), giving
`ψ ≤ (1/25)(1 − (18/25)MISS) = 1/25 − (18/625)MISS`. Since `H ⊆ B_φ`, `d(H,x) ≤ MISS`. ∎

Calibration: `C₅[2]` minus one edge has `ψ = 3/100`, `d = 1/100`; the theorem gives
`ψ ≤ 1/25 − 0.000288`. The optimal constant on this class is `≤ 1/5` (b.5). Stress-tested on 1984
random exact instances (random part sizes `≤ 4`, up to 6 deleted edges, `bip` by exhaustive cut
enumeration in Python integers): 0 violations, smallest slack `457/105625`.

### d.3 The blocking lemma for the general case

Theorem Q3-1 covers `EXTRA = 0` (no edges of `H` inside a class or between non-consecutive classes).
For general `(H,x)` near a blow-up, write `e_j` = mass of `H`-edges inside class `j`, `f_j` = mass of
`H`-edges between classes `j` and `j+2`, `E_w = Σe_j`, `F = Σf_j`. The five template cuts give
**exactly**

```
        ψ(H,x) ≤ min_{i∈ℤ₅} [ m_i m_{i+1} − miss_i + E_w + F − f_i − f_{i−1} ] ,
```

so the whole local step (S2) reduces to the following exchange statement, which I could not prove and
which is the verbatim blocking lemma of this route:

> **EXCHANGE LEMMA (open).** *There is `c > 0` such that for every triangle-free `(H,x)` and every
> `φ` with class masses `m` within `η` of `(1/5,…,1/5)`,*
> ```
> min_{i∈ℤ₅} [ miss_i + f_i + f_{i−1} ]  ≥  E_w + F + c·(MISS + E_w + F)  −  (1/25 − min_i m_i m_{i+1}) .
> ```

What is proved towards it: triangle-freeness forces, for every extra edge `uv` inside class `j`,
`miss_{j−1} ≥ min(x_u,x_v)·m_{j−1}` and `miss_j ≥ min(x_u,x_v)·m_{j+1}` (for each `w` in a
neighbouring class at most one of `uw, vw` is an edge), and in aggregate
`miss_j ≥ m_{j+1}(m_j − α_j)` where `α_j` is the `x`-weighted independence number of the extra graph
inside class `j`; likewise `miss_j ≥ min(x_u,x_w)·m_{j+1}` for each extra `(j,j+2)` edge `uw`. These
give `MISS ≳ EXTRA/8` in the balanced regime, which is *not* enough because `E_w` enters **all five**
cuts while the missing mass it forces enters only **two**; averaging the five cuts loses by a factor
`5/2`, and the minimum has to be taken with the imbalance term. That imbalance/averaging conflict is
the entire remaining content.

        psi  <=  min_i [ p_i − g_i + E_w + F − f_i − f_{i−1} ],     E_w = sum e_j , F = sum f_j .
```

**The prism is an exact witness that this family fails.** Take the prism with `x(o_j) = α = 1/5−t`,
`x(i_j) = δ = t` and the *natural* template `φ(o_j) = φ(i_j) = j` (classes = spokes, the assignment
any structural argument writes down first). Then `E_w = 5αδ` (the spokes), `F = 0`,
`g_j = 2αδ` (the pairs `o_ji_{j+1}` and `i_jo_{j+1}`), and the **best of the sixteen class-level
cuts** evaluates to

```
        α² + δ² + 5αδ  =  (α+δ)² + 3αδ  =  1/25 + 3αδ   >  1/25 ,
```

verified exactly at `t = 1/100, 1/50, 1/20, 1/10` (`57/10000, 27/2500, 9/400, 3/100` above `1/25`),
while the true value is `1/25 − 2αδ`, **below** it. The gap is `5αδ`, of the same order as the
distance itself, so no `η` makes it go away: the class-level cut family is not merely lossy, it is
**invalid as a certificate at every scale**.

What repairs it on the prism is that the prism happens to admit a *homomorphism* to `C₅`
(`o_j ↦ j`, `i_j ↦ j+1`), and at that template `EXTRA = 0`, `MISS = 5αδ`, the class cuts give
`1/25 − αδ ≤ 1/25`, and Theorem Q3-1 applies. Note also that the homomorphism template is exactly the
`d`-minimising one (`d = 5αδ` versus `15αδ` for the natural one). So:

> **the class-level cut bound is a valid certificate only at a `d`-minimising template, and even
> there it is off by a factor 2 (`1/25 − αδ` versus the truth `1/25 − 2αδ`).**

That is the precise form of the blocking lemma pass 1 recorded as EXCHANGE LEMMA. In addition I can
now say exactly how much room there is:

**Proposition P2-B (proved).** *For any `φ`, let `α_j` be the maximum `x`-weight of an independent
set inside class `j`. Then every present `(j,j+1)` edge mass obeys `q_j := p_j − g_j ≤ min(m_{j+1}α_j,
m_jα_{j+1})`, and `α_j ≤ m_j − e_j/m_j`.* (First part: for `w` in class `j+1`, `N(w) ∩ class j` is
independent because `H` is triangle-free, so its mass is `≤ α_j`; sum over `w`. Second part: every
internal edge of class `j` has an endpoint outside a maximum independent set `I`, so
`e_j ≤ (m_j − α_j)·m_j`.) *Consequently*

```
        min_j q_j  <=  (prod_j q_j)^{1/5}  <=  ((prod α_j)(prod m_j))^{1/5}  <=  (1 − sum_j e_j/m_j)/25 .
```

**Corollary (the exact size of the obstruction).** The chain above bounds the class-level cut value by
`min_j q_j + E_w + F ≤ 1/25 − (Σ_j e_j/m_j)/25 + E_w + F`, which at balanced classes `m_j = 1/5`
reads `1/25 + (4/5)E_w + F` — **above `1/25` as soon as `E_w > 0`**, so this route cannot conclude.
(The estimate is not always attained — for a *single* internal edge of weight `s` in one class the
true class-cut value is `m_1(m_0 − s) + s² ≤ 1/25`, so the route only fails when several classes carry
internal edges — but the prism above shows the *true* min over class cuts also exceeds `1/25`, so the
failure is real and not an artefact of the estimate.) The accounting is exact: internal edge mass is
monochromatic in *every one* of the five useful cuts but can be discounted only `1/5` of once.
**Factor 5.** Any repair must therefore use cuts that split classes — and the prism shows what they
look like: the two pentagons are cut at *different offsets*, which is not a class-level cut for the
natural template and is a class-level cut only for the template that is a homomorphism.

## P2.5 Literature re-check (part c), independently

* **The `1/23.5` bound has not been improved.** Balogh–Clemen–Lidický (arXiv:2103.14179, EuroComb
  2021) remains the best published global constant, together with their two density tails
  (`≤ 0.2486` and `≥ 0.3197` of `C(n,2)`). Confirmed by search; nothing later supersedes it.
* The only newer item on the problem is **arXiv:2606.28041**, "The Erdős `n²/25` max-cut conjecture
  for small multiples of five, via a per-root-MaxCut envelope and blow-up integrality", proving
  `a(5n) = n²` for `1 ≤ n ≤ 40` (`N ≤ 200`). By accepted base (3) (`a(tN) ≥ t²a(N)`, so
  `sup a(N)/N² = lim a(N)/N²`) a finite range can never extend, so this does not change the standing
  of the conjecture and confirms base (3)'s own statement of the range already secured.
* **Pikhurko–Sliačan–Tyros**, *Strong forms of stability from flag algebra calculations*, JCTB 135
  (2019) 129–178 (arXiv:1706.02612): the framework is for an objective `Λ(G) = Σ_{H} γ(H)P(H,G)`,
  a **fixed finite linear combination of subgraph densities of bounded order**, with Theorem 7.1 a
  computer-verifiable sufficient condition for perfect stability, and the input is a flag-algebra
  certificate whose value **equals** the conjectured optimum. Pass 1's two objections both stand and
  I confirm them: (1) `bip(G) = |E| − maxcut(G)` is a minimum over `2^{N−1}` cuts, not a bounded-order
  density functional (BCL themselves get one density inequality per cut construction and then take a
  `max–min` over a growing family); (2) the available certificate value `1/23.5 = 0.0425532…` is
  strictly above `1/25 = 0.04`, so the complementary-slackness data that the spectrum method reads
  off at the pentagon does not exist. Pass 2 adds a **third** obstruction, from P2.3: even granting
  both, the perfect-stability hypothesis itself is unverified, and the objects that decide it are
  Ramsey graphs whose distance-to-blow-up is `Θ(N²)` at deficit `O(1/N²)` for at least `n = 2, 3`.
