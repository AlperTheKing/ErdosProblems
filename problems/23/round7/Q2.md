## Notation (fixed here, used throughout)
- `G` triangle-free, `N = |V|`, `E = |E(G)|`.
- Fix a maximum cut `(X,Y)`. `B` = crossing (bichromatic) edges, `M` = monochromatic edges.
- `bip(G) = |E| - maxcut(G) = |M|` at any maximum cut.
- `d(v) = d_B(v) + d_M(v)`, `sigma(v) = d_B(v) - d_M(v) >= 0` (max-cut local optimality).
- `sum_v d_M(v) = 2|M|`, `sum_v d_B(v) = 2|B|`, `sum_v sigma(v) = 2|B| - 2|M|`.
