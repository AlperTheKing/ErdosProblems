# P1 — the single open step of the arc-cut chain (item 7)

STATUS: **IN PROGRESS** (stub filed 2026-07-25T18:50+03:00, updated as work proceeds).

ASSIGNMENT: prove, for every probability measure `mu` on `R/Z` with
`W in (0.12, 0.2)`, `2T < W - 1/25`, `4W^2 + Var(g) < W - 1/25`, that some level
`bound_k = (int g^k m dmu)/(int g^k dmu)` of the hierarchy is `<= 1/25`;
or reduce it to a strictly smaller statement and prove that.

## Working notation (all exact, all rational on atomic measures)

* `N(x) = (x+1/3, x+2/3)` the far arc; `g(x) = mu(N(x))`; `K` = the self-adjoint
  operator `(Kf)(x) = int_{N(x)} f dmu` on `L^2(mu)`, so `g = K1`, `h := Kg = K^2 1`.
* `W = (1/2) int g dmu`, `T = (1/2) int int_{d>1/3} d dmu dmu`, `rho := T/W in (1/3,1/2]`.
* `m = W - h`, `A = W - 2T = W(1 - 2 rho)`.
* `F(a) = int_{[a,a+1/3)} g dmu = nu([a,a+1/3))` where `nu := g dmu`, `|nu| = 2W`;
  `kappa := sup_a F(a) / (2W)`, and `B := W - sup_a F(a) = W(1 - 2 kappa)`.

## First structural observations (recorded early, proofs below)

1. `bound_0 = W - E[g^2] = W - 4W^2 - Var(g)`, `bound_1 = W - P/W` with
   `P = (1/2) int int_{d>1/3} g(x)g(y)`, i.e. `bound_1 - bound_0 = Cov(g,m)/(2W) = -Cov(g,h)/(2W)`.
2. **If `g` is constant on `supp mu` then every `bound_k` equals `bound_0 = W - 4W^2`.**
   Hence item 7 as literally stated can only be true if no measure has `g` constant,
   `W in (0.12,0.2)` and `A > 1/25`. This is the first thing to be settled.
3. The whole `bound_k` hierarchy is dominated by the single quantity `B`
   (`B <= min_b m(b) <= bound_k` for every `k >= 0`), because every `m(b)` is the arc cut at
   the 1/3-arc `N(b)` and `B` is the minimum over *all* 1/3-arcs. So the natural repaired
   target is

   **(STAR)  `min(A, B) <= 1/25` for every probability measure**, equivalently
   **`max(kappa, rho) >= 1/2 - 1/(50 W)`**, equivalently `W(1 - 2 max(kappa,rho)) <= 1/25`.

   (STAR) is tight at `C5`: there `W = 1/5`, `rho = kappa = 2/5`, `A = B = 1/25`.
