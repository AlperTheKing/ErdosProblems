# G9 — minimum degree of a minimal counterexample to Erdős #23

Assignment: raise the constant `c` in `δ(G) > cN − O(1)` for a minimal counterexample above
`4/25 = 0.16`, with a complete proof, **or** give a rigorous obstruction with an explicit
witness family.

**Outcome: the target constant `4/25` is NOT raised, and I prove it cannot be raised by the
deletion mechanism (single vertex, independent set, or arbitrary vertex set with greedy
re-insertion). The obstruction is exact and is witnessed by an explicit infinite family of
maximal triangle-free graphs with `δ = 4N/25` exactly. Two by-products: an exact O(1)
sharpening of the recorded bound, and a new unconditional theorem that closes the dense end
of the open edge-density band.**

All numbers below are exact integers / `Fraction`s; every one is produced by a script in this
directory and independently re-verified by a second, separately written implementation.

---

## 0. Notation and the two elementary inequalities

`G` triangle-free, `N = |V|`, `m = |E|`, `bip(G) = m − maxcut(G)`, `δ = δ(G)`, `Δ = Δ(G)`,
`vol(X) = Σ_{x∈X} d(x)`, `E(S) = #{edges with at least one endpoint in S}`,
`B_v = V ∖ N[v]`.

**(I) Greedy re-insertion.** For any `S ⊆ V` and any ordering `v_1,…,v_s` of `S`,
```
bip(G) ≤ bip(G − S) + Σ_i ⌊b_i/2⌋ ,     b_i = |N(v_i) ∩ ((V∖S) ∪ {v_1,…,v_{i−1}})| ,
```
because inserting `v_i` on the side holding fewer of its already-placed neighbours creates at
most `⌊b_i/2⌋` new monochromatic edges. Write `cost(S)` for the minimum of `Σ_i⌊b_i/2⌋` over
orderings. Since `Σ_i b_i = E(S)` and each floor loses at most `1/2`,
```
(E(S) − s)/2 ≤ cost(S) ≤ E(S)/2 ,   s = |S| .
```
`S = {v}` gives accepted fact 7; `S` independent gives `cost(S) = Σ_{a∈S} ⌊d(a)/2⌋`;
`S = V` gives `bip(G) ≤ m/2`.

**(II) Neighbourhood cut.** For every `v`, the cut `(N(v), V∖N(v))` is monochromatic exactly
on `E(G[V∖N(v)])`; since `N(v)` is independent, `e(V∖N(v)) = m − vol(N(v))`. Hence
```
bip(G) ≤ m − vol(N(v))  for every v,   and   bip(G) ≤ e(B_v)  for every v.
```

## 1. PROVED — Theorem A (unconditional; closes the dense end of the band)

> **Theorem A.** For every triangle-free `G`,
> `bip(G) ≤ m − max_v vol(N(v)) ≤ m − 4m²/N²`.
>
> **Corollary A1.** If `m ≥ N²/5` then `bip(G) ≤ N²/25`.
> **Corollary A2.** If `m ≤ 2N²/25` then `bip(G) ≤ N²/25` (from `bip ≤ m/2`).
> **Corollary A3.** A counterexample satisfies `2N²/25 < m < N²/5`, i.e. average degree
> strictly between `4N/25 = 0.16N` and `2N/5 = 0.4N`.
> **Corollary A4.** `δ ≥ 2N/5 ⟹ bip ≤ N²/25` (five-line proof, weaker than Häggkvist);
> `Δ ≤ 4N/25 ⟹ bip ≤ N²/25`.

*Proof.* The first inequality is (II) maximised over `v`. For the second,
`Σ_v vol(N(v)) = Σ_w d(w)²`, so `max_v vol(N(v)) ≥ (1/N)Σ_w d(w)² ≥ 4m²/N²` by
Cauchy–Schwarz. With `μ = m/N²`, `m − 4m²/N² = N²(μ − 4μ²)`, and `μ − 4μ² ≤ 1/25` iff
`4μ² − μ + 1/25 ≥ 0` iff `μ ≤ 1/20` or `μ ≥ 1/5`; the second alternative is A1, and A2
supersedes the first (`2/25 > 1/20`). ∎

*Sharpness.* `μ = 1/5` is exactly `C5[n]`: `m = 5n²`, `Σd²/N = 20n³/5n = 4n²`,
`m − 4n² = n² = bip`. `μ = 1/4` is exactly `K_{N/2,N/2}`: `N²/4 − N²/4 = 0 = bip`.
Both endpoints of Theorem A are attained.

*Verification.* Exhaustive, zero failures, on **all 102 405 connected triangle-free graphs
with `5 ≤ n ≤ 11`** (`geng -t -c`), by a brute-force max-cut written independently of the
blow-up machinery (`G9_thmA_check.cpp`, mode `A`); the strong form `bip ≤ m − max_v vol(N(v))`
is *tight* on 33 891 of them. It is also tight on the extremal graphs `K?ABBBwerwBw`
(`N=12`, `5 ≤ 25−20`), `K?BD@g]Qvo^?` (`N=12`, `5 ≤ 25−20`) and `L??ED@_~?~^_Fw`
(`N=13`, `6 ≤ 30−24`).

**Status of A relative to the assignment.** It is *not* a min-degree result: it shrinks the
open band in the edge-density parameter to `m/N² ∈ (2/25, 1/5)` exclusively, and the
min-degree consequence it yields (`δ ≥ 2N/5`) is weaker than Häggkvist. Reported because it
is unconditional, exact, and tight at both ends.

## 2. PROVED — exact O(1) sharpening of accepted fact 7

> **Theorem B.** Let `G` be a triangle-free graph on `N` vertices with `bip(G) > N²/25`
> such that every triangle-free graph on `N−1` vertices `H` satisfies `bip(H) ≤ (N−1)²/25`.
> Then
> ```
> δ(G) ≥ L(N) := 2 ( ⌊N²/25⌋ + 1 − ⌊(N−1)²/25⌋ ) .
> ```

*Proof.* `bip(G)` is an integer `> N²/25`, hence `≥ ⌊N²/25⌋ + 1`; `bip(G−v)` is an integer
`≤ (N−1)²/25`, hence `≤ ⌊(N−1)²/25⌋`. By (I) with `S={v}`,
`⌊d(v)/2⌋ ≥ bip(G) − bip(G−v) ≥ ⌊N²/25⌋ + 1 − ⌊(N−1)²/25⌋`, and `⌊d/2⌋ ≥ k ⟹ d ≥ 2k`. ∎

`L(N) ≥ ⌊(4N−2)/25⌋ + 1` for **every** `2 ≤ N ≤ 100 000` (checked exactly,
`G9_sharp_constant.py`), with gain `0,1,2` or `3`; and `L(25t) = 4·(25t)/25 + 2 = 4t + 2`
exactly. So the recorded bound improves by an explicit additive constant but **the constant
`4/25` in front of `N` is unchanged**, and §3 shows it cannot be changed.

## 3. REFUTED / BLOCKED — the deletion mechanism has ceiling exactly `4/25`

### 3a. Witness family

> **Definition.** `W_t := C5[7t, 2t, 7t, 7t, 2t]` (parts `P_0,…,P_4` around the 5-cycle).

Exact data (`G9_witness.py`, re-verified for `t=1` by a from-scratch brute force over all
`2^24` cuts of the explicit 25-vertex graph, `G9_thmA_check.cpp` mode `W1`):

| quantity | value |
|---|---|
| `N` | `25t` |
| `m` | `105 t²` |
| degrees | `P_0: 4t`, `P_1,P_4: 14t`, `P_2,P_3: 9t` |
| `δ` | `4t = 4N/25` **exactly** |
| `bip(W_t)` | `14 t² = 14N²/625 = 0.0224 N²` (so `W_t` is *not* near-extremal: `N²/25 = 25t²`) |
| `bip(W_t) − bip(W_t − v)`, `v ∈ P_0` | `2t = ⌊δ/2⌋` **exactly** |
| `bip(W_t) − bip(W_t − v)`, `v ∈ P_1,P_4` | `7t` |
| `bip(W_t) − bip(W_t − v)`, `v ∈ P_2,P_3` | `2t` |
| `min_v` drop | `2t` |
| budget `(2N−1)/25` | `2t − 1/25` |

`W_t` is maximal triangle-free (every C5 blow-up with all parts nonempty is: two vertices in
one part share a neighbour in either adjacent part; two vertices in parts at distance 2 share
the part between them). `bip(W_1) = 14` and `bip(W_1 − v) = 12` were obtained twice, once from
the blow-up identity (`min_i a_i a_{i+1} = min(14,14,49,14,14) = 14`) and once by explicit
enumeration of all `2^24` cuts of the 25-vertex graph.

### 3b. Obstruction theorem

> **Theorem C (single-vertex ceiling).** For every `t ≥ 1`, `W_t` is a maximal triangle-free
> graph on `N = 25t` vertices with `δ = 4N/25`, having a minimum-degree vertex `v` with
> `bip(W_t) − bip(W_t − v) = ⌊d(v)/2⌋`, and with `min_v (bip(W_t) − bip(W_t − v)) = 2N/25 >
> (2N−1)/25`. Consequently:
> 1. every function `h` satisfying `bip(G) − bip(G−v) ≤ h(N, d(v))` for all triangle-free `G`
>    obeys `h(25t, 4t) ≥ 2t`; the per-vertex cost `⌊d(v)/2⌋` is unimprovable at the critical
>    ratio `d/N = 4/25`;
> 2. the single-vertex deletion induction cannot yield `δ > cN` for any `c > 4/25`, no matter
>    which vertex is deleted and no matter what auxiliary potential is added.

*Proof of 2 from 1.* Assume the conjecture at `N−1` and let `G` be a counterexample at `N`.
For every `v`, `N²/25 < bip(G) ≤ bip(G−v) + h(N,d(v)) ≤ (N−1)²/25 + h(N,d(v))`, so
`h(N,d(v)) > (2N−1)/25` for every `v`, in particular for a minimum-degree vertex. To conclude
`δ > cN` one therefore needs `h(N,d) ≤ (2N−1)/25` for every `d ≤ cN`. Take `c > 4/25`,
`N = 25t` with `t` large enough that `4t ≤ cN`; then one would need
`h(25t, 4t) ≤ (2N−1)/25 = 2t − 1/25`, contradicting `h(25t,4t) ≥ 2t` from part 1. ∎

Any auxiliary potential is also blocked: if the induction hypothesis is strengthened to
`bip(H) ≤ |H|²/25 − g(|H|)` with `g ≥ 0` (needed for the conclusion to be at least the
conjecture), the step at a vertex of degree `d` requires
`⌊d/2⌋ ≤ (2N−1)/25 + g(N−1) − g(N)`, so admitting `d = cN` with `c > 4/25` forces
`g(N−1) − g(N) ≥ (c/2 − 2/25)N − O(1)`, i.e. `g(N) ≤ −Ω(N²)`, i.e. a hypothesis strictly
weaker than the conjecture. (A *graph*-dependent potential is not excluded by this argument;
see §5.)

> **Theorem D (independent-set deletion is strictly dominated).** If the single-vertex
> mechanism does not fire on `G` — i.e. `⌊d(v)/2⌋ > (2N−1)/25` for all `v` — then for every
> independent `A ⊆ V`, `|A| = a ≥ 1`,
> `Σ_{u∈A} ⌊d(u)/2⌋ > a(2N−1)/25 ≥ (2Na − a²)/25`,
> the last step being `a(2N−1) ≥ 2Na − a² ⟺ a² ≥ a`. So the independent-set mechanism does
> not fire either. Equality only at `a = 1`.

This settles the first mechanism suggested in the assignment: **deleting an independent set
can never beat the single-vertex version**, for any graph, at any `N`.

> **Theorem E (arbitrary-set deletion is defeated by the same witness).** For every nonempty
> `S ⊆ V(W_t)`, `cost(S) > (N² − (N−s)²)/25 = (2Ns − s²)/25`. Verified exactly and
> exhaustively over all `S` (part-wise, since vertices inside a part are twins) for
> `t = 1, 2, 3`, i.e. `N = 25, 50, 75` (`G9_setcheck.py`).

For all `S` except `S ⊆ P_0` the crude bound `cost(S) ≥ (E(S) − s)/2` already exceeds the
budget; for `S ⊆ P_0` the exact cost is `cost(S) = 2t|S|` (every `P_0` vertex has all `4t`
of its neighbours outside `P_0`, so its back-degree is `4t` in every ordering), and
`2t|S| > 2t|S| − |S|²/25 = (2Ns−s²)/25` strictly. Hence the arbitrary-set mechanism also has
ceiling `4/25`.

### 3c. The ceiling is *exactly* `4/25`, not merely `≥`

Exhaustive exact search over **all** C5 blow-ups with `N ≤ 60` (`G9_ceiling_search.py`):
the smallest value of `δ/N` among blow-ups that defeat the single-vertex mechanism is
`4/25`, attained by `(2,7,2,7,7)` = a rotation of `W_1`. This is forced: any defeating graph
has `⌊δ/2⌋ > (2N−1)/25`, hence `δ > (4N−2)/25`. So the mechanism's true ceiling lies in
`[(4N−2)/25, 4N/25]` and is attained.

### 3d. What a set-deletion argument would have to find

From `cost(S) ≥ (E(S) − s)/2 ≥ (sδ − e(S) − s)/2`, firing at `S` **requires**
```
δ ≤ (4N − 2s)/25 + e(S)/s + 1 .
```
So to certify `δ > cN` with `c > 4/25` one must exhibit, in every triangle-free graph with
`δ ≤ cN`, an induced subgraph with `e(S)/s ≥ (c − 4/25)N + 2s/25 − 1`, i.e. of *linear*
average degree above the ambient scale. With Mantel `e(S) ≤ s²/4` the absolute limit of the
mechanism is `δ ≤ 2N/25 + N/4 + 1 ≈ 0.33N`, but only for graphs containing near-complete-
bipartite induced subgraphs on a linear vertex set — `W_t` has none (its densest induced
subgraph is `P_2 ∪ P_3`, `e/s = 3.5t = 0.14N`), which is precisely why it defeats the whole
family.

## 5. Open loophole (the only one I did not close)

Theorem C blocks all bounds of the form `bip(G) − bip(G−v) ≤ h(N, d(v))`. It does **not**
block a bound that also reads `bip(G)` itself, e.g.
`bip(G) − bip(G−v) ≤ H(N, d(v), bip(G))`, because `W_t` has `bip = 0.0224N²`, far below the
counterexample threshold `N²/25 = 0.04N²`. The concrete open sub-question is:

> Does there exist a triangle-free `G` on `N` vertices with `bip(G) ≥ (1/25 − o(1))N²` and a
> vertex `v` with `d(v) ≤ (4/25 + ε)N` and `bip(G) − bip(G−v) = ⌊d(v)/2⌋` ?

All exact extremal graphs I could evaluate say the two properties fight each other: the
`N ≡ 0 (mod 5)` extremal graphs `C5[n]` are `2N/5`-regular, and the extremal graphs at
`N = 12,13,14` have `bip/N² = 0.0347, 0.0355, 0.0357`, i.e. `≤ 0.89 · (1/25)`, together with
`min_v` drop `= 1, 2, 1` against `⌊δ/2⌋ = 1, 2, 2`. A negative answer to the boxed question
would raise the constant; a witness would close the deletion route completely.
