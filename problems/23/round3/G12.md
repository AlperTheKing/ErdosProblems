# G12 — Erdős #23 through the covering / packing (odd-cycle transversal) formulation

Label G12. All arithmetic on acceptance paths is exact (`fractions.Fraction`, integers,
`sympy.Rational`). Every numeric claim below is reproducible from the scripts listed at the
end and was produced by at least two independent implementations.

Notation: `bip(G) = |E| − maxcut(G)` = minimum odd-cycle **edge** transversal;
`nu*(G)` = maximum fractional odd-cycle packing; `tau*(G)` = minimum fractional odd-cycle
cover. LP duality: `nu* = tau* <= bip`.

---

## 0. One-line verdict

The duality is **exact on the extremal family C5[n] and completely blocked one step past it**:
the packing LP is already strictly below the truth on the *known extremal graph at N = 14*
(`bip = 7`, `nu* = 32/5`). The mechanism does, however, yield a genuinely new unconditional
covering theorem that closes the whole **dense** half of the problem
(`|E| >= N^2/5 ==> bip <= N^2/25`), exactly tight at C5[n].

## 1. PROVED

### P1. The dual is exactly tight on the extremal family.
For every n >= 1,
```
nu*(C5[n]) = tau*(C5[n]) = n^2 = bip(C5[n]),   integrality gap 1, deficit 0.
```
*Proof (closed-form certificate pair, no computation needed).*
Primal: put `y_C = 1/n^3` on each of the `n^5` transversal 5-cycles (one vertex from each
part). A fixed edge of `C5[n]` lies in exactly `n^3` of them, so every edge load is exactly
`1`; the value is `n^5 / n^3 = n^2`.
Dual: put `x_e = 1/5` on each of the `5n^2` edges. `C5[n]` is triangle-free, so every odd
cycle has at least 5 edges and gets weight `>= 1`; the value is `5n^2/5 = n^2`. ∎

Verified exactly for n = 1..6 (`G12_a_duality.py`), and independently by cutting planes
(n <= 3) and by full odd-cycle enumeration + exact rational simplex (n <= 2).

Same phenomenon on the extremal graphs at N = 12 (both of them) and N = 13: there
`bip = nu* = |E|/5` exactly. **The extremal objects up to N = 13 are exactly the graphs on
which the trivial uniform cover `x ≡ 1/5` is LP-optimal and integral.**

### P2. The uniform fractional cover.
For every triangle-free `G`, `x ≡ 1/5` is a feasible fractional odd-cycle cover, hence
```
nu*(G) = tau*(G) <= |E(G)|/5 <= N^2/20.
```
Equality in the first inequality holds iff some fractional 5-cycle packing saturates every
edge. `C5[n]`, the N = 12, 13, 14 extremal graphs, Petersen, and every edge-transitive
triangle-free graph of odd girth 5 are all equality cases.

### P3. New covering theorem (explicit transversal).
Let `G` be triangle-free, `N` vertices, `m` edges, max degree `D`. Because `N(v)` is an
independent set, the cut `(N(v), V \ N(v))` has monochromatic edge set exactly
`E(G − N(v))`, which is therefore an explicit odd-cycle edge transversal. Hence
```
(1)  bip(G) <= min_v e(G − N(v)) = m − max_v sum_{u in N(v)} d(u)
(2)          <= m − (1/N) sum_v d(v)^2        (min <= average; sum_v sum_{u in N(v)} d(u) = sum_u d(u)^2)
(3)          <= m − 4 m^2 / N^2               (Cauchy–Schwarz)
(4)          <= N^2/16 = 0.0625 N^2           (max of x − 4x^2 at x = m/N^2 = 1/8)
(5)  bip(G) <= floor((N − D)^2/4)             (Mantel inside G − N(v), d(v) = D)
```
Bound (3) is **exactly tight on C5[n]**: `m = N^2/5` and the bound returns `N^2/25 = n^2`.

Exhaustively verified against brute-force `bip` on **all 11 563 connected triangle-free
graphs on 5..10 vertices** and on 240 random maximal triangle-free graphs on 14..20
vertices — 0 failures (`G12_d_theorem.py`, independent second implementation that builds the
cut explicitly and re-checks that the remainder is bipartite).

### P4. The dense half of the problem is closed unconditionally.
`x − 4x^2 <= 1/25` iff `x <= 1/20` or `x >= 1/5` (exact roots, `sympy`), and `x − 4x^2` is
decreasing for `x >= 1/8`. Together with the trivial `bip <= m/2`:
```
THEOREM.  Every triangle-free G satisfies bip(G) <= N^2/25 provided any one of
   (A)  |E| >= N^2/5            (= 0.2 N^2)   -- from P3(3)
   (B)  |E| <= 2N^2/25          (= 0.08 N^2)  -- from bip <= |E|/2
   (C)  Delta(G) >= 3N/5                       -- from P3(5)
Consequently the conjecture is open ONLY in the band  0.08 N^2 < |E| < 0.2 N^2  with
Delta < 3N/5.
```
`C5[n]` sits exactly on the boundary `|E| = N^2/5` of (A) and the theorem returns exactly
`N^2/25` there, so (A) is sharp and non-vacuous. (C) is new information in the range
`0.6N <= Delta < 0.84N` (the upper limit because `d(u)+d(v) <= N` on every edge and a
minimal counterexample has `delta > 0.16N`).

Regular corollary: for `d`-regular triangle-free `G`, (A) applies iff `d >= 2N/5`, which is
*exactly* the Andrásfai–Erdős–Sós threshold; so the mechanism closes the regular case above
AES and below `d <= 4N/25` and leaves precisely `0.16N < d < 0.4N` (Häggkvist already gives
the better `3N/8`).

### P5. What the LP would give if it were tight.
```
THEOREM.  If G is triangle-free and bip(G) = nu*(G), then bip(G) <= N^2/25.
Proof.  If |E| >= N^2/5 apply P4(A).  Otherwise bip = nu* <= |E|/5 < N^2/25.  ∎
```
The two halves meet *exactly* at `|E| = N^2/5` with common value `N^2/25`.
By Guenin's theorem (a signed graph is weakly bipartite iff it has no odd-K5 minor; JCTB 83
(2001) 112–168), `bip = nu*` holds for every graph whose all-negative signing has no odd-K5
minor — in particular for every K5-minor-free (hence every planar) triangle-free graph.
So Erdős #23 holds unconditionally on that class. This is a *special-class* result and is
recorded as such.

### P6. Task (b): the T-join / double-cover formulation, made precise.
```
STATEMENT 1 (cographic T-join).  Let Cut(G) <= GF(2)^E be the cut (cocycle) space and 1 the
all-ones vector.  Then   bip(G) = min{ |F| : F in 1 + Cut(G) }.
Equivalently F is admissible iff |F ∩ Z| ≡ |Z| (mod 2) for every element Z of the cycle
space: F meets every odd cycle oddly and every even cycle evenly.  This is exactly the
T-join problem of the COGRAPHIC matroid M*(G).  For planar G, M*(G) = M(G*), so it is a
genuine T-join in the dual with T = the odd faces (Hadlock's theorem).

STATEMENT 2 (double cover).  Let Gt = G x K2 and, for F <= E, let Ft be the set of BOTH
lifts of every edge of F.  Then  G − F is bipartite  <=>  in Gt − Ft the pair (v,0),(v,1)
is separated for every v.  Hence bip(G) = minimum PAIRED MULTICUT in the bipartite double
cover separating the N antipodal pairs.
```
Both verified exactly on C5, C5[2], Petersen, the N = 12 extremal graph and the 13-vertex
gap witness OK5; Statement 2 was verified as a two-way equivalence on 200 random `F` for each
graph, 0 failures (`G12_b_tjoin.py`).

**Does it give a min–max theorem summable to N^2/25? No.** The T-join min–max analogue is
exactly `bip = tau*`, which fails (Section 2). Hadlock's planar min–max is useless here:
planar triangle-free graphs have `|E| <= 2N − 4`, so `bip <= (2N−4)/5` is linear.

## 2. REFUTED (exact falsifiers)

### R1. `bip = nu*` is FALSE for triangle-free graphs. Two witnesses.

**(i) OK5, N = 13, |E| = 18, triangle-free, girth 5.** Take `K5` on `{0..4}`, keep the six
`K_{2,3}` edges `{0,1} x {2,3,4}`, and subdivide the other four edges `01, 23, 24, 34` into
paths of length 3. All ten branch paths are odd, so the odd cycles of the result correspond
bijectively (with the same parity) to the odd cycles of `K5`, and one subdivision edge per
`K5`-edge suffices to hit them.
```
bip(OK5) = 4 ,  nu*(OK5) = tau*(OK5) = 10/3 ,  integrality gap 6/5 ,  deficit 2/3.
```
Explicit transversal of size 4: the four middle edges `(5,6),(7,8),(9,10),(11,12)`; the
remainder is bipartite (checked). Lower bound `bip >= ceil(10/3) = 4` from the LP. The LP
reduces exactly to the odd-cycle LP of `K5` with unit capacity per `K5`-edge: optimum
`10/3`, attained by weight `1/3` on each of the 10 triangles of `K5` (dual: total weight
`1/3` on each `K5`-edge, spread arbitrarily along its subdivision path).
`|E| = 18` lies strictly inside the still-open density band
(`2N^2/25 = 13.52 < 18 < 33.8 = N^2/5`), so the witness is maximally relevant.
The same construction with all ten `K5` edges subdivided gives `S3(K5)`, N = 25, girth 9,
`bip = 4`, `nu* = 10/3`, same gap.

**(ii) THE HEADLINE: the extremal graph at N = 14.** `graph6 = M?AE@bH{AYN_LgBs?`,
N = 14, |E| = 32, degrees `4^6 5^8`, triangle-free.
```
bip = 7  (= a(14), an extremal object)          [two routes: all 2^13 cuts; min weight of the coset 1 + Cut(G)]
nu* = tau* = 32/5 = |E|/5 = 6.4                  [two routes: exact cutting planes; hand certificate below]
integrality gap = 35/32 = 1.09375 ,  deficit = 3/5.
```
Certificate, exact: the dual optimum is the *uniform* cover `x ≡ 1/5` (value `32/5`, every
odd cycle has `>= 5` edges); the primal optimum is a packing of **23 five-cycles** with
weights in `{1/10, 1/5, 3/10, 2/5}` under which **every one of the 32 edges has load exactly
1** — a perfect fractional C5-decomposition. Full list printed by `G12_f_n14witness.py`.

Consequence: **the packing LP cannot even reproduce the known exact value `a(14) = 7`.**
Any upper bound on `bip` obtained by bounding `nu*` is capped at `|E|/5` and is already
`3/5` short on a real extremal object.

**Exhaustive minimality.** No triangle-free graph on `N <= 11` has `bip > nu*`: all
6 + 19 + 59 + 267 + 1380 + 9832 + 90 842 connected triangle-free graphs on 5..11 vertices
were checked (`G12_e_scan.py`). Restricting to connected graphs is without loss: both `bip`
and `nu*` are additive over connected components, so a disconnected witness contains a
smaller connected one. The minimum witness size is therefore 12, 13 or 14 and we
exhibit witnesses at 13 and 14. (The N = 12 sweep over 1 144 061 graphs was launched and is
the only unresolved arithmetic in this report.)

### R2. Covering mechanisms tested for task (c), with exact breaking witnesses.
Each mechanism must return exactly `n^2` on `C5[n]` and `<= N^2/25` in general.

| mechanism | C5[n] | breaks at | exact witness |

**Ceiling of the whole independent-set-cut family (M1, M2, M3, M4 are all `<= M2`... more
precisely `M2 <= M1 <= M4 <= m − 4m^2/N^2 <= N^2/16`):**
```
sup over triangle-free G of  M2(G)/N^2  lies in [15/256, 1/16] = [0.058594, 0.0625].
```
Lower end: Clebsch graph (fully verified here: N = 16, 5-regular, alpha = 5, m = 40,
`M2 = 40 − 5*5 = 15`). Upper end proved in P3(4). For regular `G`, `M2 = d(N/2 − alpha)` and
triangle-freeness forces `Delta <= alpha`, so `M2 <= alpha(N/2 − alpha) <= N^2/16` with
equality iff `d = alpha = N/4`. The Higman–Sims graph (`srg(100,22,0,6)`, `alpha = 22`)
gives `M2 = 1100 − 22·22 = 616`, i.e. `0.0616 N^2` — within 1.5 % of the ceiling. (Using only
the Hoffman ratio bound `alpha <= 100·8/30 => alpha <= 26`, still `M2 >= 528 = 0.0528 N^2`.)
**Therefore no cut with one side independent can prove a constant better than `0.0586`, and
the mechanism provably cannot reach `1/25 = 0.04`.**

### R3. `nu*` as a falsification engine — calibrated and blocked by Andrásfai–Erdős–Sós.
Let `pi(G)` be the packing LP restricted to 5-cycles: `pi <= nu* <= bip`, and `pi` is an LP
with `O(N^5)` explicit columns, hence computable in polynomial time **without ever solving
maxcut**. So:
```
Any triangle-free G with pi(G) > N^2/25 REFUTES Erdős #23.
```
This route is exactly calibrated and exactly blocked:
* `pi <= |E|/5` always (uniform 1/5 cover); `pi(C5[n]) = n^2 = N^2/25` exactly.
* For an **edge-transitive** triangle-free graph of odd girth 5, the uniform weighting of
  all 5-cycles is feasible and optimal, so `pi = |E|/5` exactly.
* Hence `pi > N^2/25` requires `|E| > N^2/5`, i.e. average degree `> 2N/5`; for regular
  graphs Andrásfai–Erdős–Sós (`delta > 2N/5 ==> bipartite`) makes this impossible, and the
  boundary `d = 2N/5` gives exactly `N^2/25`.
```
THEOREM.  For every regular triangle-free G,  nu*(G) <= N^2/25,  with equality iff
d = 2N/5 and some fractional 5-cycle packing saturates every edge.
```
So the cheap poly-time refutation test can never fire on a regular graph. Exhaustive scans
found `max nu*/N^2 = 1/25` at N = 5, 10 and `< 1/25` for all other `N <= 11`.

## 4. BLOCKED

**Blocking lemma, verbatim:** *"For every triangle-free graph `G`, `bip(G) = nu*(G)`."*
This lemma is **FALSE** — falsified at N = 13 (`bip = 4`, `nu* = 10/3`) and, decisively, at
N = 14 **on a known extremal graph** (`bip = 7`, `nu* = 32/5`). Consequently:

1. **The packing/duality direction produces only LOWER bounds on `bip` and cannot be
   converted into the conjectured upper bound.** Every route of the form "bound the
   fractional odd-cycle packing, conclude the conjecture" terminates at the lemma above.
2. **No min–max / summable-certificate theorem exists** for odd-cycle edge covering on
   triangle-free graphs: by Guenin's theorem the LP is integral exactly on odd-K5-minor-free
   signed graphs, and OK5 is a triangle-free odd-K5 subdivision.
3. **Every cut with one side independent is capped at `>= 0.0586 N^2`** (Clebsch, Higman–Sims)
   and can never reach `N^2/25`; the family's exact ceiling is `N^2/16`.
4. The BFS-layer-parity cut is capped at `>= 0.06 N^2` (Petersen).

**Not blocked, and delivered:** the neighbourhood-cut covering theorem
`bip <= |E| − (1/N)sum_v d(v)^2 <= N^2/16`, tight on `C5[n]`, which closes the density band
`|E| >= N^2/5` and the max-degree band `Delta >= 3N/5` unconditionally with the exact
constant `1/25`.
